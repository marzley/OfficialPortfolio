Positioning

ValueBehaviour
staticNormal flow (default)
relativeNormal flow, can be nudged; becomes the reference for absolute children
absoluteRemoved from flow, placed relative to the nearest positioned parent
fixedStays on screen when scrolling (chat buttons, cookie bars)
stickyNormal until it reaches a scroll position, then sticks (headers)

z-index decides which element is on top when they overlap (only works on positioned elements). Higher number = on top.

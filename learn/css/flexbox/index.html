Flexbox layout

Flexbox lays items out in a row or column, and makes spacing and alignment easy.

PropertyWhat it does
display: flexTurns on Flexbox for the children
flex-directionrow (default) or column
justify-contentSpacing along the row: center, space-between
align-itemsAlignment across: center, flex-start
gapSpace between items
flex-wrap: wrapLets items move to the next line on small screens

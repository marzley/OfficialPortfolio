Web, software and tech services

Tech skills are among the best-paid earning methods, locally and internationally. Kenyan businesses need websites, M-Pesa payments, systems and IT support; international clients hire developers, testers and specialists remotely. Most methods here need a laptop and months of learning, but the free hub lessons and career roadmaps take you through them.

What these methods share

  • Proof beats certificates: a portfolio of working projects (Build real projects).
  • Security and ethics: protect client data, never leave secrets in code, and only test systems you're authorised to test.
  • Contracts and deposits for direct clients (discovery, quotes and contracts).

160. Business website development

What it is: Building websites for businesses, schools, churches and organisations. How it works: Brief → design → build (code or WordPress) → content → launch → training and care plan.

SkillsHTML, CSS, JavaScript or WordPress; hosting; SEO basics
Cost & equipmentLaptop, internet
Where to find workLocal businesses, referrals, freelance platforms, agencies
PaymentProject fee with deposits; M-Pesa/bank
Realistic earningsLow–medium to medium–high
Time to first incomeMonths (learning) then weeks per project

How to start: Follow the web developer roadmap and the business website project. Pros: Huge local demand. Cons & risks: Scope creep; clients slow with content. Scam warning: Overpayment cheque scams from "international clients". Kenya notes: See web design business.

161. WordPress development and customisation

What it is: Building and customising WordPress sites, themes and plugins. How it works: Themes, page builders or custom code; plugin setup; performance and security.

SkillsWordPress, PHP basics, CSS
Cost & equipmentLaptop; premium themes/plugins optional
Where to find workSMEs, bloggers, agencies, freelance marketplaces
PaymentProject or hourly
Realistic earningsLow–medium to medium
Time to first incomeWeeks to months

How to start: WordPress basics; build 3 sample sites. Pros: Large market. Cons & risks: Nulled (pirated) themes contain malware; use licensed ones. Scam warning: As above. Kenya notes: Many Kenyan SMEs choose WordPress for affordability.

162. E-commerce store development

What it is: Building online shops with carts, payments and order management (WooCommerce, Shopify or custom). How it works: Product setup → payments (M-Pesa, cards) → delivery options → launch → training.

SkillsWeb development, payment integration (e-commerce project)
Cost & equipmentLaptop
Where to find workRetailers, fashion brands, manufacturers
PaymentProject fee + maintenance
Realistic earningsMedium
Time to first incomeMonths then weeks

How to start: Build a demo store with M-Pesa sandbox checkout. Pros: High-value projects. Cons & risks: Payment issues must be handled carefully. Scam warning: As above. Kenya notes: M-Pesa checkout is a must-have for Kenyan shops.

163. M-Pesa and payment integration

What it is: Integrating M-Pesa (Daraja: STK push, C2B, B2C), cards and PayPal into websites, apps and systems. How it works: Sandbox development → secure callbacks → go-live with the business's paybill/till.

SkillsBack-end development, APIs, security (M-Pesa project)
Cost & equipmentLaptop, hosting with HTTPS
Where to find workBusinesses, developers, agencies, start-ups
PaymentPer integration or project
Realistic earningsMedium
Time to first incomeMonths then weeks

How to start: Build a working sandbox demo and document it. Pros: Specialist local demand. Cons & risks: Payment bugs cost clients money; test thoroughly. Scam warning: Never handle clients' money directly through your own accounts. Kenya notes: One of the most requested tech skills in Kenya.

164. Custom web systems (school, inventory, booking, SACCO)

What it is: Building database-driven systems for specific business needs. How it works: Requirements → design → development → testing → deployment → support contract.

SkillsFull-stack development, databases, security
Cost & equipmentLaptop, hosting
Where to find workSchools, SACCOs, clinics, shops, NGOs
PaymentMilestone payments + maintenance
Realistic earningsMedium to high
Time to first incomeMonths

How to start: Build one of the project guides to production quality. Pros: Large, recurring contracts. Cons & risks: Complex; long-term support obligations. Scam warning: As above. Kenya notes: Local systems with M-Pesa and SMS integration have strong demand.

166. API and back-end development

What it is: Building servers and APIs that power apps and websites. How it works: API design → implementation → security → tests → deployment.

SkillsNode, PHP, Python or Go; databases; auth (REST API project)
Cost & equipmentLaptop
Where to find workStart-ups, agencies, international remote roles
PaymentHourly/project/salary
Realistic earningsMedium to high
Time to first incomeMonths

How to start: Publish a documented API project on GitHub. Pros: Well-paid remote work. Cons & risks: Competitive international market. Scam warning: Fake "job offers" asking you to run suspicious code or pay for equipment. Kenya notes: Kenyan developers work remotely for global companies.

167. Website maintenance and care plans

What it is: Monthly updates, backups, security monitoring, uptime checks and small edits for existing websites. How it works: Monthly retainer with a defined list of tasks and a report.

SkillsWordPress/hosting, security basics (website maintenance)
Cost & equipmentLaptop
Where to find workYour past clients, businesses with neglected sites, agencies
PaymentMonthly retainer
Realistic earningsLow per site; medium with many sites
Time to first incomeWeeks

How to start: Offer care plans to every website client. Pros: Recurring income. Cons & risks: Responsibility when sites break. Scam warning: As above. Kenya notes: Many Kenyan websites are abandoned after launch and get hacked.

168. Website speed optimisation

What it is: Making slow websites load faster (images, caching, code, hosting). How it works: Audit with Lighthouse → fixes → before/after report.

SkillsWeb performance (website speed)
Cost & equipmentLaptop
Where to find workSite owners, agencies, freelance platforms
PaymentPer site
Realistic earningsLow–medium
Time to first incomeWeeks

How to start: Optimise your own site; show score improvements. Pros: Clear, measurable results. Cons & risks: Some hosting limits can't be fixed. Scam warning: As above. Kenya notes: Mobile-data users in Kenya benefit hugely from fast sites.

169. Website security cleanup (hacked sites)

What it is: Removing malware from hacked websites, closing vulnerabilities and hardening security. How it works: Backup → scan → clean files and database → update → secure → monitor.

SkillsWeb security, server access, WordPress internals
Cost & equipmentLaptop, security tools
Where to find workSite owners, hosting companies, agencies
PaymentPer cleanup + monthly protection
Realistic earningsLow–medium to medium
Time to first incomeWeeks to months

How to start: Learn web security and practise on test sites you own. Pros: Urgent, valued service. Cons & risks: Responsibility; re-infections. Scam warning: Only work on sites you're authorised to access. Kenya notes: Many Kenyan SME sites run outdated plugins and get hacked.

170. Hosting and domain reselling

What it is: Selling web hosting, domains and email accounts to clients, often bundled with setup. How it works: Reseller accounts from hosting providers; you bill clients annually.

SkillsHosting management, DNS (DNS records), customer support
Cost & equipmentReseller account fees
Where to find workYour web clients, SMEs
PaymentAnnual billing
Realistic earningsLow (adds up with many clients)
Time to first incomeWeeks

How to start: Use a reputable reseller plan; register domains in clients' names. Pros: Recurring revenue. Cons & risks: You handle support when servers fail. Scam warning: Never hold clients' domains hostage; it's unethical and damages trust. Kenya notes: .co.ke domains are registered through accredited registrars.

171. Business email and Google Workspace / Microsoft 365 setup

What it is: Setting up professional email, shared drives and user accounts for organisations. How it works: Domain verification → users → email migration → training.

SkillsDNS, admin consoles, user training
Cost & equipmentLaptop
Where to find workSMEs, schools, NGOs
PaymentSetup fee + support
Realistic earningsLow to low–medium
Time to first incomeWeeks

How to start: Set up professional email for your own domain first. Pros: Quick projects. Cons & risks: Migration mistakes can lose email. Scam warning: As above. Kenya notes: Schools and SMEs moving from Gmail addresses to professional domains.

172. IT support and computer repair

What it is: Fixing computers, installing software, upgrading hardware, removing malware and setting up printers. How it works: Walk-in, on-site or remote support; per job or monthly contracts.

SkillsHardware and Windows troubleshooting (computer maintenance)
Cost & equipmentToolkit, spare parts, bootable USBs
Where to find workHomes, offices, schools, cyber cafés
PaymentPer job or monthly
Realistic earningsLow to medium
Time to first incomeDays

How to start: Follow the IT support roadmap. Pros: Constant demand. Cons & risks: Responsibility for client data. Scam warning: Don't install pirated software for clients. Kenya notes: Laptop upgrades (SSD, RAM) are popular and affordable services.

Where to find workOffices, schools, hotels, apartments

How to start: Practise in Packet Tracer; assist an installer. Pros: Practical, local demand. Cons & risks: Physical work; equipment costs. Scam warning: As above. Kenya notes: Wi-Fi hotspot billing systems for estates are popular (Wi-Fi hotspot billing).

What it is: Installing cameras, recorders and remote viewing for homes and businesses. How it works: Site assessment → equipment → installation → app setup → maintenance.

SkillsElectrical basics, networking, installation safety

Where to find workHomes, shops, schools, estates
PaymentProject fee + maintenance
Realistic earningsLow–medium to medium
Time to first incomeWeeks

How to start: Train with an experienced installer; learn privacy obligations. Pros: High demand. Cons & risks: Working at heights; privacy laws. Scam warning: As above. Kenya notes: Follow data protection guidance on CCTV (signage, retention).

SkillsSee the cybersecurity roadmap

Where to find workSMEs, schools, SACCOs, security firms, bug bounty programmes

Summary

  • Tech methods range from websites, WordPress, e-commerce and M-Pesa integration to systems, apps, APIs, maintenance, security, hosting, email setup, IT support, networks, CCTV, QA, data, Excel, automation, AI chatbots, databases, cloud, cybersecurity and teaching.

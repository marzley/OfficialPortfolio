Programming and web development: where to earn

Coding is one of the best-paid online skills, and one of the few where a developer in Nyeri or Kisumu can earn the same as one in London. It takes longer to learn (months, not days), but the demand never stops: every business wants a website, every SACCO wants a system, every startup wants an app.

Learn it free here: HTML → CSS → JavaScript → PHP & MySQL for websites, Flutter or React Native for apps, Python and SQL for data and automation.

Local clients: the most underrated market

Kenyan businesses pay well for software that saves them time or makes them money:

  • Schools: fee management, results, SMS to parents.
  • Hospitals and pharmacies: patients, billing, stock, NHIF/SHA claims workflows.
  • SACCOs and chamas: contributions, loans, statements.
  • Shops and supermarkets: POS with M-Pesa, stock and reports.
  • TVETs and colleges: student portals, CBET documentation (see the CBET Planner story).

Find them through people you know, LinkedIn, local business groups, county events and by showing a working demo. A real demo beats any CV.

Build a portfolio that gets hired

  1. 3 real projects beat 20 tutorials: a business website, a system with login and a database, and an app or API.
  2. Put the code on GitHub with a clear README (what it does, screenshots, how to run it).
  3. Deploy them so people can click and try (cheap cPanel hosting, or free tiers).
  4. Write a short case study for each: the problem, what you built, the result.
  5. Get testimonials from your first clients (even if you gave a discount).

Ranges depend on features, quality and the client. Always quote by scope (a written list of features), take a deposit (usually 40 to 50%), and charge for changes outside the scope. See How much does a website cost in Kenya?.

Mistakes that cost developers money

  • No written scope: the project never ends.
  • Handing over all code before final payment.
  • No backups or security: one hacked site ruins your reputation.
  • Competing only on price: compete on reliability, speed and support instead.
  • Stopping learning: frameworks change; spend a few hours every week learning.

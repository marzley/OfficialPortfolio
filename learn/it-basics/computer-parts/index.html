Parts of a computer

Hardware

PartWhat it doesWhat to look for
CPU (processor)The "brain" that runs instructionsIntel Core i3/i5/i7 or AMD Ryzen 3/5/7; newer generation = faster
RAM (memory)Short-term working space for open programs8 GB minimum for programming today; 16 GB is comfortable
StorageKeeps files and programs permanentlySSD (much faster) over HDD; 256 GB+
MotherboardConnects everything
GPU (graphics)Draws the screen; needed for gaming, video editing, AIBuilt-in is fine for coding and office work
PSU / batteryPowerLaptop battery health matters on second-hand machines
Input devicesKeyboard, mouse, touchpad, microphone, camera
Output devicesMonitor, printer, speakers

Software

  • Operating system (OS): Windows, macOS, Linux, Android, iOS. Manages hardware and runs apps.
  • Application software: browsers, Word, Excel, VS Code, games.
  • Firmware/BIOS/UEFI: low-level software that starts the computer.

Units

1 byte = 8 bits · 1 KB ≈ 1,000 bytes · 1 MB ≈ 1,000 KB · 1 GB ≈ 1,000 MB · 1 TB ≈ 1,000 GB.

Buying a second-hand laptop for learning

Aim for: Core i5 (8th gen or newer) or Ryzen 5, 8–16 GB RAM, SSD, good battery, working keyboard and screen hinges. Test all ports, the Wi-Fi and the webcam before paying.

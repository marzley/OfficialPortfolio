What is a computer? Hardware, software and how it works

A computer is an electronic machine that accepts data, processes it following instructions, stores it and gives results. Your laptop, your phone, an ATM, a supermarket till and a car's engine controller are all computers.

Data vs information

  • Data: raw facts. 78, 84, 90, Amina
  • Information: processed data that means something. "Amina's average is 84, grade A."

The IPO cycle: Input → Process → Output (+ Storage)

Example: paying for groceries at a supermarket till.

StageWhat happens
InputThe barcode scanner reads each item; the cashier types the quantity
ProcessThe computer looks up prices, adds them, applies VAT
OutputThe screen shows the total; the printer prints a receipt
StorageThe sale is saved for stock and accounting

Hardware and software

HardwareSoftware
The physical parts you can touchPrograms: instructions that tell hardware what to do
Keyboard, CPU, screen, printer, hard diskWindows, Android, Word, Chrome, WhatsApp

Software comes in two main types:

  • System software runs the computer: the operating system (Windows, macOS, Linux, Android, iOS), drivers and utilities.
  • Application software does tasks for you: word processing (Word), spreadsheets (Excel), browsers (Chrome), accounting (QuickBooks), games.

Characteristics of computers

  • Speed: billions of operations per second.
  • Accuracy: correct results if the input and instructions are correct. ("Garbage in, garbage out.")
  • Storage: huge amounts of data kept for years.
  • Diligence: never tired or bored by repetitive work.
  • Versatility: the same machine can type a letter, play music and do accounts.

But computers can't think for themselves: they only follow instructions.

Today's phone is millions of times more powerful than the computers that guided the Apollo moon landing.

Computers in Kenya today

M-Pesa, eCitizen, KRA iTax, hospital records, school management systems, farming apps and online jobs all depend on computers. Basic computer skills are now needed in almost every job, and deeper skills (coding, networking, data) are in high demand.

Why everyone needs to understand computers

Computers are no longer only for offices. A boda boda rider uses a smartphone (a computer) for maps and M-Pesa, a farmer checks prices and weather, a teacher enters marks into a school system, a nurse records patients on a tablet, and a shopkeeper uses a till that's really a small computer. Understanding how computers work helps you choose the right device, use it confidently, fix simple problems, protect your data and learn more advanced skills like programming and networking.

When people say a computer is "slow", the cause is usually too little RAM, a nearly full or old hard disk (HDD), too many programs starting automatically, or malware, not always the CPU.

Think about a supermarket till: barcode scanner (input), CPU looks up the price (process), screen and receipt printer (output), sales saved (storage), and the M-Pesa payment confirmation arrives over the network.

Software layers

When you press the power button, the firmware checks the hardware (POST), finds the operating system on the storage drive and loads it into RAM. This is called booting.

How a computer represents everything with 0s and 1s

Computers store everything (numbers, text, photos, music) as binary: patterns of 0s and 1s (bits), because electronic switches are either off or on.

DataHow it's stored
The number 5101 in binary
The letter A01000001 (code 65 in ASCII/Unicode)
A photoMillions of pixels, each a number for red, green and blue
MusicThousands of sound measurements per second

Eight bits make a byte, enough for one simple character. You'll learn more in the storage units lesson.

Think about it: A shop owner says, "My computer has a 1 TB hard disk, so it must be fast." What would you explain?Show answer

Storage size (1 TB) is how much it can keep, not how fast it works. A large spinning HDD can still be slow; speed depends more on having an SSD, enough RAM (8 GB or more), a reasonably recent processor and a clean system without too many startup programs or malware.

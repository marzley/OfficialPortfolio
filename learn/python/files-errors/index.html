Errors and exceptions

Programs meet bad input: letters instead of numbers, division by zero, missing files. try/except handles problems gracefully instead of crashing.

Validating input

Common errors

ErrorMeaning
SyntaxErrorCode is written wrongly (missing colon, bracket)
IndentationErrorWrong spaces at the start of a line
NameErrorUsing a variable that doesn't exist (typo?)
TypeErrorWrong type, e.g. "5" + 3
ValueErrorRight type, bad value, e.g. int("abc")
KeyError / IndexErrorMissing dictionary key / list position
ZeroDivisionErrorDividing by zero

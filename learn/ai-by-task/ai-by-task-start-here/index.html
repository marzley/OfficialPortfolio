Start here: how to choose the best AI for any task

"Which AI is the best?" has no single answer. The best AI for writing a CV is not the best for drawing a logo, editing a TikTok video or fixing a PHP error. This subject goes task by task, and for each one shows:

  • the best tools right now, and what each is best at
  • a step-by-step workflow that gets good results
  • ready prompts you can copy
  • costs, limits and risks to watch for

Tools change fast

New AI tools appear every month and prices change often. The tools here are well-established at the time of writing, but always check the current features, free plan and price on the tool's own website. The ways of choosing and working in this subject stay useful even when the tools change.

Two kinds of AI tools

TypeExamplesUse it when
All-rounder chat assistantsChatGPT, Claude, Gemini, Microsoft CopilotMost everyday tasks: writing, explaining, planning, summarising, simple images, basic code
Specialist toolsCanva (design), Perplexity (research), GitHub Copilot (coding), ElevenLabs (voice), CapCut (video)You need something the all-rounders do poorly, or you do the task every day

Rule of thumb: start with one chat assistant. Add a specialist tool only when you keep hitting a limit.

The six questions to ask before choosing

  1. **Quality: is it good at this task?** Test it with your own real task, not a demo.
  2. Cost: is the free plan enough? Many tools limit free use per day. Pay only when the tool saves you real time or earns you money.
  3. Privacy: where does my data go? Never paste passwords, ID numbers, M-Pesa statements, client secrets or patients' records into an AI tool. Check if the tool uses your chats for training and how to turn that off.
  4. Accuracy: does it show sources? For facts, prefer tools that link to sources, then open the sources.
  5. Fit: does it work where I work? Copilot inside Word and Excel, Gemini inside Gmail and Google Docs, Canva for designers.
  6. Rights: can I use the output commercially? Especially for images, music, voices and logos for clients.

How to test tools fairly (15 minutes)

  1. Pick one real task you do often, e.g. "write a Facebook post for my salon's Saturday offer".
  2. Give exactly the same prompt to two or three tools.
  3. Compare the results on: accuracy, tone, how much editing you needed, speed.
  4. Keep the winner for that task. Write it down in a "my AI toolkit" note.

Learn prompting first

Every tool in this subject works better with good prompts. If you haven't yet, do the prompting masterclass and read when AI is wrong.

Think about it: You run a small cyber café in Thika. You want help with CVs for customers, posters for your shop and answering WhatsApp questions faster. Which tools would you try first, and why not ten different apps?Show answer

Start with one chat assistant for CV wording and WhatsApp replies (it handles most writing), and Canva for posters. Two tools with free plans cover almost everything. Add a specialist only when you hit a real limit, because learning ten apps wastes time and money and spreads your customers' data across many companies.

Summary

  • There is no single "best AI"; the best tool depends on the task.
  • Start with one all-rounder chat assistant; add specialist tools only when needed.
  • Choose with six questions: quality, cost, privacy, accuracy, fit and rights.
  • Test tools with your own real task and the same prompt.
  • Tools and prices change often: check the tool's website.

Page layout, headers, page numbers and printing

Reports, proposals, project documents and CVs are judged partly on how they look on the page. This lesson covers the layout tools that make documents look professional in Microsoft Word (and the same ideas in Google Docs and LibreOffice Writer).

Page setup (Layout tab)

SettingTypical choiceWhere
Paper sizeA4 (standard in Kenya), not LetterLayout → Size
OrientationPortrait; Landscape for wide tablesLayout → Orientation
MarginsNormal (2.54 cm) or as your college requiresLayout → Margins
Columns1; 2–3 for newslettersLayout → Columns

Documents downloaded from the internet are often set to Letter size, which prints with odd gaps on A4 paper. Always check Size → A4 before printing.

Headers, footers and page numbers

  • Insert → Header / Footer: text that repeats on every page (document title, organisation name, confidentiality notice).
  • Insert → Page Number: choose position (e.g. bottom centre). Use Format Page Numbers for "Page 1 of 10" or roman numerals.
  • Different first page (in Header & Footer tools): no header on a cover page.

Section breaks: different layouts in one document

A report often needs a cover page with no number, preliminary pages numbered i, ii, iii, then chapters numbered 1, 2, 3, and maybe one landscape page for a big table.

  1. Put the cursor where the new part starts.
  2. Layout → Breaks → Section Break (Next Page).
  3. In the new section's header/footer, turn off Link to Previous.
  4. Change page number format or orientation for just that section.
BreakDoes
Page break (Ctrl + Enter)Starts a new page, same section
Section break (Next Page)New page and a new section with its own settings
Column breakMoves text to the next column

Never press Enter many times to reach a new page: when you edit earlier text, everything shifts. Use Ctrl + Enter.

Paragraph spacing and line spacing

Home → Paragraph dialog:

  • Line spacing: 1.15 or 1.5 is comfortable; many colleges require 1.5 or double for assignments.
  • Spacing before/after: e.g. 6 pt after each paragraph instead of pressing Enter twice.
  • Indentation: first-line indent or hanging indent (for references).
  • Keep with next: stops a heading being left alone at the bottom of a page.

Professional touches

FeatureWhere
Cover pageInsert → Cover Page
FootnotesReferences → Insert Footnote (Alt + Ctrl + F)
Captions for figures and tablesReferences → Insert Caption, then Insert Table of Figures
Watermark ("DRAFT", "CONFIDENTIAL")Design → Watermark
Page bordersDesign → Page Borders (use rarely)
Citations and bibliographyReferences → Insert Citation, Bibliography (APA, Harvard...)

Printing and PDFs

  1. File → Print (Ctrl + P) shows a preview: check every page before printing.
  2. Choose pages (e.g. 1-3, 5), copies, one-sided or double-sided, and pages per sheet.
  3. To share a document that must look the same everywhere, File → Save As → PDF (or Export → Create PDF).

PDFs keep fonts and layout fixed and can't be casually edited, which makes them right for CVs, invoices, reports and applications.

Checklist before submitting a report

  • [ ] A4, correct margins
  • [ ] Consistent heading styles and an automatic table of contents
  • [ ] Page numbers (none on the cover)
  • [ ] Figures and tables captioned
  • [ ] Spell check done (F7), names and figures double-checked
  • [ ] Saved as PDF if submitting online

Why layout and printing skills matter

Reports, proposals, CVs, school projects, minutes, letters and tender documents are judged partly by how they look. Consistent margins, clear headings, page numbers, a table of contents and a clean PDF signal professionalism. University projects and government tenders often have strict formatting rules (margins, font, spacing, cover page), and documents that don't follow them can lose marks or be rejected.

Styles: the foundation of a professional document

Instead of formatting each heading by hand, use Styles (Home tab):

StyleUse
TitleDocument title on the cover
Heading 1Chapter or main section ("1. Introduction")
Heading 2Sub-section ("1.1 Background")
Heading 3Smaller sub-section
NormalBody text
CaptionLabels for figures and tables

Benefits:

  • Change the look of every heading at once (right-click the style → Modify).
  • The Navigation Pane (View → Navigation Pane, or Ctrl + F) lists headings so you can jump and rearrange sections by dragging.
  • An automatic table of contents is built from heading styles.
  • Screen readers and PDF bookmarks use heading styles.

Automatic table of contents

  1. Apply Heading 1/2/3 styles to all headings.
  2. Place the cursor on a blank page after the cover → References → Table of Contents → choose a style.
  3. After editing, right-click the table → Update Field → Update entire table.

Never type a table of contents by hand: page numbers change every time you edit.

Captions, lists of figures and cross-references

  • Select a picture or table → References → Insert Caption → "Figure 1: Sales by branch".
  • References → Insert Table of Figures creates a list of figures automatically.
  • References → Cross-reference inserts "see Figure 3" that updates when figures are renumbered.

Academic reports often need these, along with numbered headings (Home → Multilevel List).

Citations and references

References → Insert Citation stores sources (books, websites, journals) and formats them in APA, Harvard or other styles; Bibliography inserts the list automatically. Check what style your institution requires. Always cite sources you use, including websites and AI-assisted research you verified, to avoid plagiarism.

Page numbers in a typical report

A report often needs: no number on the cover, roman numerals (i, ii, iii) for preliminary pages (declaration, abstract, table of contents), and 1, 2, 3 starting at Chapter 1.

  1. Insert a Section Break (Next Page) after the cover and another before Chapter 1 (Layout → Breaks).
  2. Double-click the footer of section 2 → untick Link to Previous → Insert Page Number → Format Page Numbers → choose i, ii, iii and "Start at i".
  3. In section 3, untick Link to Previous, set format 1, 2, 3, "Start at 1".
  4. On the cover (section 1), tick Different First Page or delete its number.

Turn on Show/Hide ¶ (Ctrl + Shift + 8) to see section breaks and fix layout problems.

Templates: don't start from scratch

Create a template for documents you make often (invoices, letters, reports) with your logo, styles, headers and footers:

  1. Design the document once.
  2. File → Save As → Word Template (.dotx).
  3. New documents based on it keep the layout; the template itself stays unchanged.

Businesses use letterhead templates so every staff member's letters look the same.

Mail merge: personalised letters, certificates and labels

Mail merge creates many personalised documents from one template and a list (Excel or Google Sheets exported):

  1. Prepare an Excel list with columns: Name, School, Amount, Phone.
  2. Mailings → Start Mail Merge → Letters (or Labels, Envelopes).
  3. Select Recipients → Use an Existing List → choose the Excel file.
  4. Place cursor and Insert Merge Field («Name», «Amount»).
  5. Preview Results, then Finish & Merge → Edit Individual Documents or print.

Uses: fee reminders to parents, certificates for 200 trainees, invitation letters, envelope labels. Format numbers in Excel as text (or use field switches) so amounts display correctly.

Printing like a professional

SettingUse
Print Preview (Ctrl + P)Check every page before printing
Pages: 1-3, 7Print specific pages
Print on both sidesSave paper (manual duplex on printers without automatic duplex)
Pages per sheetHandouts, drafts
Scale to paper sizeFit A4 documents on other paper
CollatedPrint complete copies in order

Before printing 50 copies, print one and check it.

PDF export options

File → Save As → PDF (or Export → Create PDF):

  • Options → Create bookmarks using Headings gives a clickable outline in PDF readers.
  • Minimum size (publishing online) reduces file size for email and uploads.
  • Check "Document structure tags for accessibility".
  • Protect sensitive PDFs with a password using a PDF tool if needed.

Common mistakes

MistakeFix
Pressing Enter many times to start a new pageCtrl + Enter (page break)
Spaces to centre or indent textAlignment buttons, indents and tabs
Manual numbering of headings and figuresMultilevel lists and captions
Typed table of contentsReferences → Table of Contents
Different fonts all over the documentUse Styles consistently
Pictures jumping aroundLayout Options → In Line with Text, or anchor correctly

Practice

  1. Format a 5-page report with a cover, a table of contents, Heading 1/2 styles and captions.
  2. Set up roman numerals for preliminary pages and arabic numbers from Chapter 1.
  3. Create a letterhead template (.dotx) with a logo, header and footer.
  4. Use mail merge to create 10 personalised certificates from an Excel list.
  5. Export to PDF with heading bookmarks and check the file size.
Think about it: A student's 40-page project has a typed table of contents, and after adding a section, all page numbers are wrong the day before submission. How should it have been done?Show answer

Apply Heading styles to every heading and insert an automatic table of contents (References → Table of Contents). After any edit, right-click the table and choose Update entire table: all page numbers and headings refresh in seconds.

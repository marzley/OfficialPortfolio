Files and folders

Moving around

CommandMeaning
cd /var/wwwGo to an absolute path (starts with /)
cd projectsGo into a folder inside the current one
cd ..Up one level
cd ~ or cdYour home folder
cd -Back to the previous folder
ls -laList all files (including hidden .files) with details

Creating, copying, moving, deleting

rm -rf deletes without asking. Double-check the path. There is no undo.

Looking inside files

Finding things

The pipe | sends one command's output into the next. > writes output to a file (overwrite), >> appends.

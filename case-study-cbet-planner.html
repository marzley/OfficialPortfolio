CBET Planner: CBET documentation for TVET trainers

By Kelvin Wanyoike · 27 Sep 2026 · 2 min read

Visit the live site ↗

The problem

Trainers in Kenya’s TVET institutions work under Competency-Based Education and Training (CBET). For every unit they teach, they prepare learning plans, session plans, information sheets, assessments and marking schemes, all following the curriculum and the required format. Done by hand, this takes hours for each unit and has to be repeated whenever a curriculum changes.

The goal

Give trainers a tool that turns their curriculum into ready-to-edit documentation, so they spend less time on paperwork and more time teaching, while keeping full control over the final documents.

What I built

  • Curriculum upload. Trainers start from the curriculum or an existing learning plan for their unit.
  • Document generation. The platform drafts learning plans, session plans, information sheets, assessments and marking schemes in the CBET structure.
  • Step-by-step flow. Each document builds on the previous one, from learning plan to session plans, so everything stays consistent.
  • Review and edit. Trainers can adjust anything before downloading and using it.
  • Guides and help pages that walk new users through each tool.

How it’s built

  • A web application that works in any browser, on phones and computers.
  • User accounts so each trainer’s documents stay private and saved.
  • Search-friendly public pages, so trainers can find it on Google when they search for CBET help.

The result

CBET Planner is live at cbetplanner.co.ke and shows up on Google for searches like “CBET Planner”, with its guides listed right under the main result. Trainers can go from curriculum to a full set of documents in one place instead of starting each one from a blank page.

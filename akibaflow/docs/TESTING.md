# Testing
`php tests/run.php [filter]` — dependency-free harness; needs a scratch DB (`akibaflow_test`; override with `TEST_DB_NAME`, `DB_USER`, `DB_PASS`) with the schema migrated (`DB_NAME=akibaflow_test php bin/migrate.php --fresh`). **Tests TRUNCATE every table of that DB.** HTTP tests start `php -S` on port 8099.

Coverage (48 tests): schedules (daily/weekly/biweekly/monthly/month-end/leap/custom/one-time/time-zone boundary) · acceptance scenarios from the spec (daily 3 days → 300; pay 200 → 100; next day → 200; weekly Monday 500×2; monthly 5th 2000×2) · idempotent generation · partial/advance/credit · reversal incl. spent credit · waivers · effective-dated plan changes · joins/exits/pauses · penalties · payment flow end-to-end through the real callback handler · duplicate/forged/mismatched/malformed callbacks · **forked-process concurrency** (4 simultaneous callbacks; 6 simultaneous payments) · dual-control reversal · M-PESA request building/timeouts · C2B · reminders escalation & dedupe · notification queue · expenses workflow · ledger balance & immutability · reconciliation invariants · HTTP security (unauth, CSRF, cross-group IDOR, role limits, admin separation, amount tampering, callbacks, throttling, enumeration, headers/CSP, XSS escaping, CSV export).
`php tests/crawl.php <base> <gid> -v` logs in as each demo role and fetches every page (finds 5xx/PHP warnings).
**Not covered:** browser automation of every flow (screens were checked manually via Playwright screenshots at 1280px and 390px), accessibility audit tooling, load/performance tests, live Daraja/SMS/SMTP.

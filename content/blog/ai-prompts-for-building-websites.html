Good prompts turn an AI assistant into a capable web team. Copy these, replace the brackets with your details, and use them in order. Always review and test what the AI produces. For the full process, read how to build a website with AI like a pro.

Planning

  1. “Act as a web strategist. My business is [description] in [town]. Ask me 10 questions to plan a website that brings in customers.”
  2. “Based on my answers, propose a sitemap, the goal of each page and the main call to action.”
  3. “List the words my customers in [town] would search on Google to find a business like mine.”
  4. “Compare these 3 competitor websites [paste links or text]: what they do well, what’s missing, how I can stand out.”

Content

  1. “Write the Home page using only these facts: [paste]. Headline, intro, 3 services, why us, call to action. Under 250 words.”
  2. “Write an About page that tells our story honestly: [facts]. Warm, not boastful.”
  3. “Write 8 FAQs with short answers for a [type] business, using these policies: [paste].”
  4. “Rewrite this page so a 14-year-old could understand it, keeping it professional: [paste].”
  5. “Translate these key sections into natural Kiswahili: [paste].”

Design

  1. “Suggest a colour palette with hex codes and two Google Fonts for a [type] brand that feels [adjectives]. Check text contrast.”
  2. “Describe a mobile-first layout for the Home page, section by section.”

Code

  1. “Write semantic, accessible HTML and CSS for a responsive navigation bar with a mobile menu button. No frameworks.”
  2. “Create a services grid with 6 cards using CSS Grid, 1 column on phones, 3 on desktop.”
  3. “Write a contact form with labels, validation for a Kenyan phone number, and a clear success message.”
  4. “Explain this code line by line: [paste].”
  5. “This doesn’t work: [describe]. Here’s the code and the error: [paste]. Find the cause and fix it.”
  6. “Add a WhatsApp chat button that opens a chat with a pre-filled message.”

SEO

  1. “Write a page title (under 60 characters) and meta description (under 155 characters) for this page: [paste].”
  2. “Generate LocalBusiness JSON-LD structured data with these details: [name, address, phone, hours].”
  3. “Suggest descriptive alt text for these images: [describe each].”
  4. “Plan 10 blog posts that answer questions my customers search for.”

Speed, security and launch

  1. “Review this page for performance problems and suggest fixes: [paste].”
  2. “Review this form handler for security issues (validation, spam, injection): [paste].”
  3. “Write a launch checklist for a small business website: testing, SEO, analytics, backups.”
  4. “Write a simple monthly maintenance checklist for this website.”

Prompts work better when you…

  • Give real facts and examples instead of asking the AI to invent them.
  • Build one section at a time and test each one.
  • Ask the AI to review its own work for accessibility, speed and security.

AI can now write code, generate designs and draft every page of a website. Beginners use it to get a website that looks fine on day one and breaks on day thirty. Professionals use it to work faster without giving up quality. Here’s the professional way, step by step, with prompts you can copy.

Step 1: plan before you prompt

AI can’t guess your business. Write a one-page brief first, then use AI to improve it:

“Act as a web strategist. I run a catering business in Thika serving weddings and corporate events. Help me plan a website: goals, target customers, the pages I need, what each page must contain, and the main call to action. Ask me questions first.”

You should end with a sitemap (Home, Services, Gallery, Pricing, About, Contact), a goal for each page and a list of facts only you know (prices, areas served, phone, Till number).

Step 2: write the content with AI, from your facts

“Write the Home page text for this business using only these facts: [paste]. Sections: headline, short intro, 3 services, why choose us, testimonial placeholder, call to action to WhatsApp. Friendly, simple English, under 250 words.”

  • Replace placeholders with real testimonials and photos. Never publish fake reviews.
  • Check every fact: prices, phone numbers, locations.
  • Ask for a Kiswahili version of key sections if your customers prefer it.

Step 3: design with structure, not just colours

Ask AI for a design system: “Suggest a colour palette (with hex codes), two fonts from Google Fonts and a layout for a catering website that feels warm and premium. Make sure text has enough contrast to be readable.” Then sketch the layout in Figma or Canva, or describe it to the AI section by section.

Step 4: choose how to build it

  • AI website builders (Wix, Hostinger, Framer, Durable and similar): fastest for a simple brochure site; monthly fees and less control.
  • WordPress with AI help: flexible, huge plugin choice; AI helps write content and fix settings.
  • Hand-coded HTML/CSS/JavaScript with an AI coding assistant: fastest pages, full control, best for learning and for custom features. This is how professionals get top speed and SEO.

Step 5: code with AI, one section at a time

Don’t ask for “a whole website” in one prompt. Build section by section:

“Write semantic, accessible HTML and CSS for a hero section: headline, short text, two buttons (WhatsApp and View menu), a background image with a dark overlay. Mobile-first, no frameworks, CSS variables for colours.”

Then the services grid, the gallery, the contact form, the footer. After each piece:

  • Read the code and ask the AI to explain anything you don’t understand.
  • Test it on a phone-sized screen.
  • Ask: “Review this code for accessibility, performance and security problems.”

Coding assistants such as GitHub Copilot, Cursor and Claude Code can work inside your project folder. Learn the basics in our free HTML, CSS and JavaScript lessons so you can judge what the AI writes.

Step 6: the professional checklist AI often forgets

  • Speed: compress images (WebP), lazy-load them, avoid heavy scripts.
  • Mobile: test on a real cheap Android phone.
  • SEO: unique page titles and meta descriptions, one H1 per page, alt text on images, a sitemap, and a Google Business Profile.
  • Security: HTTPS, protected forms (validation and spam protection), no secret keys in front-end code, updated plugins.
  • Accessibility: readable contrast, labels on form fields, keyboard navigation.
  • Payments: M-Pesa STK push needs a secure server-side integration. See how M-Pesa payments work on websites.
  • Analytics and backups.

Step 7: test and launch

Run your site through our free website check, Google PageSpeed Insights and a link checker. Ask three friends to complete a task (“book a tasting”) on their phones and watch where they struggle. Fix, then launch on a proper domain like yourbusiness.co.ke.

Mistakes beginners make with AI websites

  • Publishing generic AI text that sounds like every other website.
  • Copying code they don’t understand, then being unable to fix it.
  • Fake testimonials and stock photos pretending to be real work.
  • Ignoring speed, security and SEO because the site “looks fine”.
  • Putting API keys or payment secrets in JavaScript.

# Formatting documents like a pro: fonts, paragraphs, spacing, lists and consistent design

A well-formatted document is easier to read, looks professional and earns trust, whether it's a CV, a business proposal, a school report or meeting minutes. Poor formatting (random fonts, uneven spacing, text pushed around with spaces and Enter keys) looks careless and breaks when someone else opens the file. This unit teaches professional formatting in **Microsoft Word** step by step, with the equivalent in **Google Docs**.

:::note What you will learn
- Character formatting: fonts, sizes, emphasis, colour, case
- Choosing fonts that look professional
- Paragraph formatting: alignment, line and paragraph spacing, indents
- Bullets and numbering, multilevel lists
- Tabs, borders, shading and columns
- Format Painter and clearing formatting
- Show/hide formatting marks and why "spaces for alignment" is a mistake
- A consistent formatting checklist
:::

## Character formatting

Select text first (double-click a word, triple-click a paragraph, `Ctrl+A` for everything), then use **Home → Font** (Word) or the toolbar (Docs).

| Format | Word | Google Docs | Use |
|---|---|---|---|
| Bold | `Ctrl+B` | `Ctrl+B` | Headings, key terms |
| Italic | `Ctrl+I` | `Ctrl+I` | Titles of works, foreign words, emphasis |
| Underline | `Ctrl+U` | `Ctrl+U` | Rarely (looks like a link) |
| Strikethrough | Home → abc | `Alt+Shift+5` | Showing deletions |
| Superscript / subscript | `Ctrl+Shift+=` / `Ctrl+=` | `Ctrl+.` / `Ctrl+,` | 1st, m², H₂O |
| Change case | `Shift+F3` | Format → Text → Capitalisation | UPPER, lower, Title |
| Increase/decrease size | `Ctrl+]` / `Ctrl+[` | `Ctrl+Shift+.` / `,` | |
| Font dialog | `Ctrl+D` | | All options in one place |

### Choosing fonts

| Use | Good choices | Size |
|---|---|---|
| Body text (reports, letters) | Calibri, Arial, Aptos, Times New Roman, Georgia | 11–12 pt |
| Headings | The same font in bold, or a complementary font | 14–20 pt |
| CVs | Calibri, Arial, Cambria, Garamond | 10.5–12 pt |
| Posters/flyers | Bold sans-serif for headlines | Large |

Rules:
- Use **one or two fonts** per document.
- Avoid decorative fonts (Comic Sans, Algerian) in formal documents.
- **Serif** fonts (Times New Roman, Georgia) have small strokes on letters and suit printed long text; **sans-serif** (Arial, Calibri) look clean on screens. Both are fine; be consistent.
- Check institution requirements: many universities require Times New Roman 12, double or 1.5 spacing.

### Colour and highlight

Keep body text black or very dark grey. Use colour sparingly for headings or one brand colour. Highlighting is for drafts and review, not final documents.

## Paragraph formatting

A **paragraph** in Word is everything up to where you pressed Enter (shown as ¶ when formatting marks are visible). Paragraph settings are in **Home → Paragraph** and **Layout → Paragraph**.

### Alignment

| Alignment | Shortcut | Use |
|---|---|---|
| Left | `Ctrl+L` | Most body text (easiest to read) |
| Centre | `Ctrl+E` | Titles, cover pages |
| Right | `Ctrl+R` | Dates in some letters, numbers |
| Justify | `Ctrl+J` | Newspaper-style even edges; can create big gaps between words |

### Line spacing

Space between lines **within** a paragraph: Home → Line and Paragraph Spacing (or `Ctrl+1` single, `Ctrl+5` 1.5, `Ctrl+2` double). 1.15 is a comfortable default; 1.5 or double for assignments if required.

### Paragraph spacing (before and after)

Space **between** paragraphs. Set it (e.g. 6 pt before, 8 pt after) in Layout → Spacing, instead of pressing Enter twice. Benefits: consistent gaps, no empty paragraphs that shift when editing.

### Indents

| Indent | Use | How |
|---|---|---|
| Left/right indent | Quotations, notes | Layout → Indent, or drag the ruler markers |
| First-line indent | Traditional paragraphs | Paragraph dialog → Special → First line |
| Hanging indent | Reference lists (APA style), numbered lists | Paragraph dialog → Special → Hanging |

Turn on the ruler: **View → Ruler**.

## Formatting marks: see what's really there

Click **¶** (Home → Show/Hide, `Ctrl+Shift+8`) to show hidden marks:

| Mark | Meaning |
|---|---|
| `¶` | Paragraph end (Enter) |
| `·` | Space |
| `→` | Tab |
| `↵` | Line break (`Shift+Enter`) |
| `......Page Break......` | Manual page break |

:::warning Don't align with spaces or Enter
Pressing the spacebar many times to line text up, or Enter many times to move to a new page, creates documents that break as soon as fonts, printers or content change. Use **tabs**, **alignment**, **paragraph spacing**, **page breaks** (`Ctrl+Enter`) and **tables** instead. Showing formatting marks reveals these problems.
:::

## Lists

### Bullets and numbering

Home → **Bullets** or **Numbering**. Tips:
- Use bullets when order doesn't matter; numbers for steps.
- Press **Enter twice** to end a list, or click the button again.
- **Tab** demotes an item (sub-point); **Shift+Tab** promotes it.
- Right-click a number → **Restart at 1** or **Continue numbering**.
- Typing `1.` and a space (or `*` and a space) starts a list automatically (AutoFormat).

### Multilevel lists

Home → **Multilevel List** for outlines like 1, 1.1, 1.1.1 (great for policies, reports and legal documents). Linking multilevel lists to heading styles numbers headings automatically.

## Tabs

**Tab stops** line text up precisely, for example in letters, forms and simple lists with prices:

1. Click the tab selector at the left end of the ruler to choose left, centre, right or **decimal** tab.
2. Click on the ruler where you want the stop.
3. Press `Tab` in your text to jump to it.
4. **Leaders** (dotted lines) are set in Paragraph → Tabs (e.g. `Unga ........ KSh 180`).

For anything with many rows, a **table** (borders hidden if needed) is usually easier.

## Borders, shading and columns

- **Borders and shading:** Home → Borders → Borders and Shading: a box around a note, a line under a letterhead, shaded headings.
- **Page borders:** Design → Page Borders (certificates, invitations; avoid in formal reports).
- **Columns:** Layout → Columns (newsletters, brochures); insert a **column break** (Layout → Breaks) to control where text moves to the next column.

## Format Painter and clearing formatting

- **Format Painter** (paintbrush on Home): select formatted text → click the brush → click/drag over other text to copy the formatting. **Double-click** the brush to apply to several places; press `Esc` to stop.
- **Clear All Formatting** (Home → eraser icon, or `Ctrl+Space` for character formatting): removes formatting, useful for text pasted from websites.
- **Paste options:** after pasting, choose **Keep Text Only** to drop strange website formatting (or `Ctrl+Shift+V` in Google Docs).

## Professional formatting checklist

- [ ] One or two fonts; consistent sizes for body and each heading level
- [ ] Headings using **Styles** (next lesson), not manual bold + size
- [ ] Consistent line and paragraph spacing; no double Enters
- [ ] No spaces/Enters used for alignment; tabs, tables and page breaks used instead
- [ ] Lists formatted with bullets/numbering; consistent punctuation in list items
- [ ] Left-aligned body text (or justified if required)
- [ ] Page numbers, headers/footers where appropriate
- [ ] Spell check done; formatting marks checked
- [ ] Saved as PDF for sharing final versions

:::think A document looks perfect on your computer, but when your lecturer opens it, the text on page 3 has moved to the top of page 4 and the cover page is split. What likely caused this?
The document probably used many Enter presses and spaces to position text, and different fonts/printer settings on the lecturer's computer changed line lengths, pushing everything down. Using page breaks, paragraph spacing, styles and sending a **PDF** prevents this.
:::

## Practice tasks

1. Format a one-page letter: Calibri 11, 1.15 line spacing, 8 pt after paragraphs, no empty paragraphs.
2. Turn on formatting marks in a document someone else made and fix any spaces/Enters used for alignment.
3. Create a multilevel list for a club constitution (1, 1.1, 1.1.1).
4. Make a price list with right tabs and dot leaders.
5. Paste text from a website, then clean it with Keep Text Only and Format Painter.

## Summary

- Character formatting: fonts, sizes, bold/italic, super/subscript, case; choose one or two professional fonts.
- Paragraph formatting: alignment, line spacing, spacing before/after, indents (first-line, hanging).
- Show formatting marks (¶) and never align with spaces or Enters; use tabs, tables, page breaks.
- Lists: bullets, numbering, multilevel lists; Tab/Shift+Tab to change levels.
- Borders, shading, columns, Format Painter, Clear Formatting and paste options keep documents clean and consistent.

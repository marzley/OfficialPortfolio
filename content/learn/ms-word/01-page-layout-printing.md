# Page layout, headers, page numbers and printing

Reports, proposals, project documents and CVs are judged partly on how they **look on the page**. This lesson covers the layout tools that make documents look professional in Microsoft Word (and the same ideas in Google Docs and LibreOffice Writer).

## Page setup (Layout tab)

| Setting | Typical choice | Where |
|---|---|---|
| **Paper size** | A4 (standard in Kenya), not Letter | Layout → Size |
| **Orientation** | Portrait; Landscape for wide tables | Layout → Orientation |
| **Margins** | Normal (2.54 cm) or as your college requires | Layout → Margins |
| **Columns** | 1; 2–3 for newsletters | Layout → Columns |

> Documents downloaded from the internet are often set to **Letter** size, which prints with odd gaps on A4 paper. Always check Size → A4 before printing.

## Headers, footers and page numbers

- **Insert → Header / Footer**: text that repeats on every page (document title, organisation name, confidentiality notice).
- **Insert → Page Number**: choose position (e.g. bottom centre). Use **Format Page Numbers** for "Page 1 of 10" or roman numerals.
- **Different first page** (in Header & Footer tools): no header on a cover page.

## Section breaks: different layouts in one document

A report often needs a cover page with no number, preliminary pages numbered i, ii, iii, then chapters numbered 1, 2, 3, and maybe one landscape page for a big table.

1. Put the cursor where the new part starts.
2. **Layout → Breaks → Section Break (Next Page)**.
3. In the new section's header/footer, turn off **Link to Previous**.
4. Change page number format or orientation for just that section.

| Break | Does |
|---|---|
| Page break (**Ctrl + Enter**) | Starts a new page, same section |
| Section break (Next Page) | New page and a new section with its own settings |
| Column break | Moves text to the next column |

> Never press Enter many times to reach a new page: when you edit earlier text, everything shifts. Use Ctrl + Enter.

## Paragraph spacing and line spacing

**Home → Paragraph** dialog:

- **Line spacing**: 1.15 or 1.5 is comfortable; many colleges require 1.5 or double for assignments.
- **Spacing before/after**: e.g. 6 pt after each paragraph instead of pressing Enter twice.
- **Indentation**: first-line indent or hanging indent (for references).
- **Keep with next**: stops a heading being left alone at the bottom of a page.

## Professional touches

| Feature | Where |
|---|---|
| **Cover page** | Insert → Cover Page |
| **Footnotes** | References → Insert Footnote (Alt + Ctrl + F) |
| **Captions** for figures and tables | References → Insert Caption, then Insert Table of Figures |
| **Watermark** ("DRAFT", "CONFIDENTIAL") | Design → Watermark |
| **Page borders** | Design → Page Borders (use rarely) |
| **Citations and bibliography** | References → Insert Citation, Bibliography (APA, Harvard...) |

## Printing and PDFs

1. **File → Print** (Ctrl + P) shows a **preview**: check every page before printing.
2. Choose pages (e.g. `1-3, 5`), copies, one-sided or **double-sided**, and pages per sheet.
3. To share a document that must look the same everywhere, **File → Save As → PDF** (or Export → Create PDF).

PDFs keep fonts and layout fixed and can't be casually edited, which makes them right for CVs, invoices, reports and applications.

## Checklist before submitting a report

- [ ] A4, correct margins
- [ ] Consistent heading styles and an automatic table of contents
- [ ] Page numbers (none on the cover)
- [ ] Figures and tables captioned
- [ ] Spell check done (F7), names and figures double-checked
- [ ] Saved as PDF if submitting online

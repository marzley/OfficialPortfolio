# Website, app and game testing platforms: UserTesting, Userlytics, Trymata, uTest and more

Testing pays the best of the easy-entry work: you use a website or app, think aloud, and report what confused you or what broke. Clear speaking and good English help a lot.

:::warning Check before you rely on it
Countries, payment options and minimum payouts change often. Confirm on each platform's official website, and never pay anyone to join.
:::

## 38. UserTesting

**What it is:** The best-known usability testing platform.

| | |
|---|---|
| Tasks | Recorded tests where you speak your thoughts while using a site or app; live interviews |
| How you're paid | PayPal |
| Kenya | Open to many countries; test supply is higher for some countries |
| Realistic earnings | Low to medium per test; live interviews pay more |
| Best for | Clear speakers with a quiet place and a mic |

**How to start:** Do the practice test well: it decides your access. Speak continuously and specifically.
**Pros:** Good pay per test. **Cons:** Tests go fast; screeners filter you out.
**Watch out:** Never share test content: it's confidential.

## 39. Userlytics

**What it is:** A usability testing platform with recorded and moderated tests.

| | |
|---|---|
| Tasks | Recorded think-aloud tests, surveys, card sorting |
| How you're paid | PayPal |
| Kenya | Open to many countries |
| Realistic earnings | Low to medium |
| Best for | Testers with good audio |

**How to start:** Complete your profile; respond fast to invites.
**Pros:** Fair pay per test. **Cons:** Irregular invites.
**Watch out:** Use a quiet room; poor audio gets rejected.

## 40. Trymata (formerly TryMyUI)

**What it is:** A usability testing platform for websites and apps.

| | |
|---|---|
| Tasks | Think-aloud tests with written follow-up |
| How you're paid | PayPal |
| Kenya | Open to many countries |
| Realistic earnings | Low to medium |
| Best for | Native-level English speakers |

**How to start:** Pass the qualification test.
**Pros:** Simple tests. **Cons:** Limited volume.
**Watch out:** Follow the tasks exactly.

## 41. Testbirds

**What it is:** A German crowdtesting company for apps, websites and devices.

| | |
|---|---|
| Tasks | Bug testing, usability tests, device tests |
| How you're paid | PayPal |
| Kenya | Open to many countries |
| Realistic earnings | Low to medium |
| Best for | People with various devices |

**How to start:** Register your devices; join projects.
**Pros:** Bug bounties per valid bug. **Cons:** Projects are selective.
**Watch out:** Report bugs clearly with steps and screenshots.

## 42. uTest

**What it is:** A large community for software testers (Applause).

| | |
|---|---|
| Tasks | Functional testing, bug reporting, usability, payments testing |
| How you're paid | PayPal or Payoneer |
| Kenya | Open to many countries; projects depend on location and devices |
| Realistic earnings | Low to medium; experienced testers more |
| Best for | People who want to grow into software testing (QA) |

**How to start:** Complete the uTest Academy courses; start with small projects.
**Pros:** Path into a QA career. **Cons:** Competitive at first.
**Watch out:** Duplicate or low-quality bug reports hurt your rating.

## 43. Test IO

**What it is:** A crowdtesting platform paying for valid bugs in websites and apps.

| | |
|---|---|
| Tasks | Exploratory testing, bug reports, reproductions |
| How you're paid | PayPal |
| Kenya | Open to many countries |
| Realistic earnings | Low to medium |
| Best for | Detail-oriented testers |

**How to start:** Learn bug report writing; join test cycles quickly.
**Pros:** Pays per valid bug. **Cons:** Competition for bugs.
**Watch out:** Follow scope: testing outside scope isn't paid.

## 44. Ubertesters

**What it is:** A crowdtesting company for mobile apps and websites.

| | |
|---|---|
| Tasks | Functional and usability testing |
| How you're paid | PayPal or Payoneer |
| Kenya | Open to many countries |
| Realistic earnings | Low to medium |
| Best for | Mobile testers |

**How to start:** Register devices and apply to projects.
**Pros:** Varied projects. **Cons:** Irregular.
**Watch out:** Keep test apps confidential.

## 45. PlaytestCloud

**What it is:** A platform where players test mobile games before release.

| | |
|---|---|
| Tasks | Play and record your reaction to new games |
| How you're paid | PayPal |
| Kenya | Open to several countries; check availability |
| Realistic earnings | Low per test |
| Best for | Mobile gamers |

**How to start:** Speak your thoughts as you play.
**Pros:** Fun. **Cons:** Limited tests.
**Watch out:** Keep games confidential.

## 46. Respondent

**What it is:** A research platform paying for interviews with professionals and consumers.

| | |
|---|---|
| Tasks | Paid interviews, focus groups, diary studies |
| How you're paid | PayPal |
| Kenya | Many studies target specific countries; some are remote and global |
| Realistic earnings | Medium to high per interview |
| Best for | Professionals (IT, business, health) and specific consumers |

**How to start:** Complete your profile with your real job details; apply to studies that match.
**Pros:** High pay per session. **Cons:** Many applications needed.
**Watch out:** Never misrepresent your job: you'll be removed.

## 47. User Interviews

**What it is:** A platform connecting researchers with participants for paid studies.

| | |
|---|---|
| Tasks | Interviews, usability tests, surveys |
| How you're paid | Paid by researchers, often via PayPal or gift cards |
| Kenya | Many studies are US-focused; some accept global participants |
| Realistic earnings | Medium per study |
| Best for | People who fit specific study criteria |

**How to start:** Apply to studies that genuinely fit you.
**Pros:** Good pay per study. **Cons:** Selective.
**Watch out:** Honesty is required.

## Summary

- Testing pays best among easy-entry work: UserTesting, Userlytics, Trymata, Testbirds, uTest, Test IO, Ubertesters and PlaytestCloud.
- Respondent and User Interviews pay well for interviews when your profile fits.
- Clear audio, honest profiles and confidentiality protect your access.

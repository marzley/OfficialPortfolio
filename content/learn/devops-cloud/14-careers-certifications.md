# DevOps and cloud careers: certifications, portfolio projects and finding work

Cloud and DevOps skills are in demand in Kenya and worldwide, including for remote work. Employers want proof you can build, automate and run systems safely. This lesson gives you a plan.

## Typical entry paths

| Starting point | Next step |
|---|---|
| IT support / helpdesk | Linux and cloud basics → junior cloud or sysadmin role |
| Web developer | CI/CD, Docker and deployment → DevOps-minded developer → DevOps engineer |
| Network technician | Cloud networking, security → cloud network/security engineer |
| Fresh graduate | Projects + entry certification → internships, junior roles |

## Certifications worth considering

| Certificate | Level | Notes |
|---|---|---|
| **AWS Certified Cloud Practitioner** | Beginner | Cloud concepts and AWS basics |
| **AWS Certified Solutions Architect – Associate** | Associate | Highly requested for cloud roles |
| **Microsoft Azure Fundamentals (AZ-900)** | Beginner | Azure basics |
| **Microsoft Azure Administrator (AZ-104)** | Associate | Running Azure environments |
| **Google Cloud Associate Cloud Engineer** | Associate | Deploying and managing on Google Cloud |
| **HashiCorp Terraform Associate** | Associate | Infrastructure as code |
| **Certified Kubernetes Administrator (CKA)** | Professional | Hands-on Kubernetes exam |
| **Linux Foundation / Red Hat certifications** (e.g. LFCS, RHCSA) | Associate | Proves Linux skills |

Check current exam codes, prices and discounts on the official sites; providers update them often and sometimes offer free training and exam vouchers through programmes and events.

**Certificates open doors; projects and interviews get the job.**

## Portfolio projects that impress

1. **Deploy a full app** with Docker, Nginx, HTTPS, CI/CD and backups ([project lesson](./?track=devops-cloud&lesson=deploy-real-app)).
2. **Terraform a cloud environment:** VPC, subnets, a load balancer, an auto scaling group and a managed database, with a README and architecture diagram (then destroy it to save money).
3. **Kubernetes app** on a local cluster (kind/minikube) with deployments, services, ingress, Helm and a GitHub Actions pipeline.
4. **Monitoring stack:** Prometheus and Grafana dashboards with alerts for your app.
5. **Automation scripts:** Bash or Python scripts for backups, log cleanup or server setup.

Put everything on GitHub with clear READMEs, diagrams and "what I learned" notes. Write short LinkedIn posts or blog articles about what you built.

## Where to find work

- Banks, telcos, fintechs and insurers
- Software companies and startups
- Hosting and managed IT service providers
- NGOs and international organisations
- Remote roles for global companies (see [remote professional jobs](./?track=earn-directory&lesson=remote-professional-jobs-methods))
- Freelancing: server setup, migrations, CI/CD pipelines, Docker setups, cloud cost reviews (see [Freelancing](./?track=freelancing&lesson=freelancing-roadmap) and [cloud and DevOps services](./?track=earn-directory&lesson=web-tech-services-methods))

Job titles: Junior DevOps Engineer, Cloud Support Associate, Cloud Engineer, Systems Administrator, Site Reliability Engineer, Platform Engineer, Infrastructure Engineer.

## Interview preparation

- **Explain a project end to end:** architecture, decisions, problems you solved.
- **Troubleshooting questions:** "The site is down: what do you check?"
- **Linux and networking basics:** permissions, processes, DNS, ports, subnets.
- **Hands-on tasks:** write a Dockerfile, a CI workflow or a small Terraform config.
- **Security and cost awareness:** least privilege, secrets, budgets.

## Keep learning

- Official free training: AWS Skill Builder, Microsoft Learn, Google Cloud Skills Boost.
- Communities: local tech meetups, cloud user groups in Nairobi, online communities.
- Practise regularly in sandboxes and free tiers, with billing alerts on.

:::think You have two certificates but no projects. A recruiter asks, "Show me something you've built." What should you do over the next month?
Build and publish one complete project: deploy an app with Docker, HTTPS, CI/CD and backups, define the infrastructure in Terraform, add monitoring, and document it with a diagram and README on GitHub. Then write a short post explaining it. One real, well-documented project is more convincing than more certificates.
:::

## Summary

- Many paths lead in: IT support, web development, networking or graduate projects.
- Certifications (AWS, Azure, Google Cloud, Terraform, CKA, Linux) help; projects matter more.
- Build and document real projects: deployment, Terraform, Kubernetes, monitoring, automation.
- Look in banks, fintechs, telcos, startups, hosting firms, NGOs, remote roles and freelancing.

# Smart technology and telecom installation trades

Homes, offices, estates and schools keep adding internet, security and backup power. Each installation trade below can be a job, a contract role or your own small business. They build on the basics of network installation (method 173), CCTV (174), TV and satellite dishes (257) and solar (382).

## What these methods share

- **Safety first:** work at height, mains electricity and batteries can kill. Get proper training and protective equipment.
- **Licences:** electrical and solar work in Kenya needs the right EPRA licence; work for ISPs usually comes with their own vetting and training.
- **Warranty and records:** give written quotes, receipts and warranty terms, and keep photos of every installation.

## 782. Fibre-to-the-home (FTTH) installation technician

**What it is:** Connecting homes and offices to fibre internet: running drop cables, fitting termination boxes and setting up routers.
**How it works:** An internet provider or its contractor assigns jobs → install → test → customer signs off.

| | |
|---|---|
| Skills | Cable handling, basic networking, ladder safety |
| Cost & equipment | Tools and test kit are often provided by the contractor; your own ladder, toolkit and transport help |
| Where to find work | ISP installation contractors, estate fibre projects |
| Payment | Per installation or monthly wage |
| Realistic earnings | Low to medium |
| Time to first income | Weeks (after training) |

**How to start:** Apply to ISP contractors in your area; take a short fibre or networking course; be reliable and neat.
**Pros:** Steady demand as fibre spreads. **Cons & risks:** Long days, heights, targets.
**Scam warning:** Fake 'job placement' fees: real contractors don't charge you to work.
**Kenya notes:** Fibre is spreading fast in towns and estates across Kenya, so installers are needed beyond Nairobi.

## 783. Fibre splicing and OTDR testing

**What it is:** Joining fibre cables with a fusion splicer and testing links with an OTDR (a fault-finding meter).
**How it works:** Contractors hire splicers for new routes, repairs after cable cuts and building backbones.

| | |
|---|---|
| Skills | Fusion splicing, fibre testing, reading OTDR traces |
| Cost & equipment | High if you own a splicer and OTDR; many start by using the employer's |
| Where to find work | Telecom contractors, ISPs, county and road projects |
| Payment | Daily rate or per joint |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Train on splicing (short practical courses exist), work under an experienced splicer, then build a reputation.
**Pros:** Skilled, better-paid niche. **Cons & risks:** Expensive equipment; emergency call-outs at night.
**Scam warning:** Cheap 'certificates' without hands-on practice won't get you hired.
**Kenya notes:** Cable cuts from roadworks are common, so repair splicers stay busy.

## 784. Telecom tower and rooftop site technician

**What it is:** Maintaining mobile network sites: antennas, power systems, generators and batteries.
**How it works:** Tower companies and their maintenance contractors send technicians to scheduled and fault visits.

| | |
|---|---|
| Skills | Electrical basics, climbing safety, telecom equipment |
| Cost & equipment | Training and safety certification (work at height); usually employer-provided gear |
| Where to find work | Tower companies, maintenance contractors |
| Payment | Monthly salary or contract |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Get an electrical or telecom certificate, then a work-at-height safety course; apply to maintenance contractors.
**Pros:** Structured career path. **Cons & risks:** Dangerous if safety rules are ignored; travel to remote sites.
**Scam warning:** Never climb without certified harness training, whatever you're promised.
**Kenya notes:** Thousands of sites across Kenya need regular maintenance.

## 785. Satellite internet installation (e.g. Starlink)

**What it is:** Mounting satellite internet dishes, running cables and setting up Wi-Fi for homes, lodges, farms and schools far from fibre.
**How it works:** The client buys the kit → you survey for a clear view of the sky → mount, cable and configure.

| | |
|---|---|
| Skills | Mounting, cabling, Wi-Fi setup |
| Cost & equipment | Ladder, drill, mounting hardware, cable |
| Where to find work | Rural homes, lodges, farms, schools, NGOs |
| Payment | Per installation |
| Realistic earnings | Low to medium |
| Time to first income | Weeks |

**How to start:** Learn the kit's setup guide, install for a few clients at a fair price, and collect reviews.
**Pros:** Big need in areas without fibre. **Cons & risks:** Travel costs; you depend on the client buying kit.
**Scam warning:** Don't resell kits or subscriptions in ways the provider doesn't allow; buy from official channels.
**Kenya notes:** Satellite internet has been available in Kenya since 2023 and suits remote lodges, farms and schools.

| | |

|---|---|

**Kenya notes:** Gated homes and estates are growing in every Kenyan town.

## 791. Inverter and battery backup installation

**What it is:** Installing inverters and batteries so homes and businesses keep power during blackouts.
**How it works:** Assess load → size system → install → test → maintain.

| | |
|---|---|
| Skills | Electrical installation, sizing calculations |
| Cost & equipment | Tools, meters; licensed electrician status |
| Where to find work | Homes, shops, clinics, offices |
| Payment | Per installation |
| Realistic earnings | Medium |
| Time to first income | Months |

**Kenya notes:** Power cuts make backup power a common purchase for Kenyan homes and businesses.

**What it is:** Buying used or ex-corporate laptops, repairing, cleaning and upgrading them, and reselling with a warranty.
**How it works:** Source → test and fix → upgrade (SSD, RAM) → clean and reinstall legal software → sell.

| | |
|---|---|
| Skills | Hardware repair, software setup |
| Cost & equipment | Stock money, tools, parts |
| Where to find work | Students, small businesses, online buyers |
| Payment | Per sale |
| Realistic earnings | Low to medium |

**How to start:** Start with a few units; give an honest condition report and a short warranty.

**Kenya notes:** Ex-corporate laptops are popular with Kenyan students; honest warranties build trust.

| | |
|---|---|
| Skills | Electronics repair, sorting, record keeping |
| Cost & equipment | Storage, transport; licences for handling e-waste |
| Where to find work | Offices, schools, homes, repair shops |
| Payment | Sales of refurbished items and parts, collection fees |
| Realistic earnings | Low to medium |

**How to start:** Learn the NEMA rules for e-waste handling; partner with a licensed recycler.

**Kenya notes:** NEMA regulates e-waste; licensed recyclers exist in Nairobi and other towns.

## Summary

- Installation trades include fibre (FTTH) installation, fibre splicing, tower maintenance, satellite internet, electric fences, gate automation, access control, biometric attendance, smart homes, inverter backup, laptop refurbishing and licensed e-waste handling.
- Safety training, the right licences (EPRA for electrical and solar work) and neat, documented work build a reputation.
- Respect privacy and the Data Protection Act when installing systems that collect personal or biometric data.

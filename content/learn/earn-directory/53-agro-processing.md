# Agro-processing and value addition

Selling raw produce at harvest time earns the least. Processing, drying, storing and packaging adds value and lets you sell when prices are better. This builds on agricultural value addition (method 286).

## What these methods share

- **Standards:** food products need KEBS standards marks and county public health approval.
- **Hygiene and packaging:** clean processing and good labels earn shelf space.
- **Raw material:** secure steady supply from farmers or groups.

## 829. Mobile maize shelling and threshing service

**What it is:** Taking a motorised sheller or thresher to farms to shell maize or thresh beans and grains.
**How it works:** Farmers book → shell on-site → charge per bag.

| | |
|---|---|
| Skills | Machine operation and maintenance |
| Cost & equipment | Sheller/thresher, transport (motorbike or tractor) |
| Where to find work | Smallholder farmers, groups, traders |
| Payment | Per bag |
| Realistic earnings | Medium in harvest seasons |
| Time to first income | Weeks |

**How to start:** Buy or lease a machine before harvest; book farmers through chamas and groups.
**Pros:** Fast returns in season. **Cons & risks:** Seasonal; machine breakdowns.
**Scam warning:** Agree prices per bag before work.
**Kenya notes:** Harvest seasons in the Rift Valley and Western Kenya bring heavy demand.

## 830. Hermetic storage and grain drying

**What it is:** Selling hermetic storage bags and offering drying services so farmers store grain safely and sell later.
**How it works:** Dry grain properly → store in hermetic bags or silos → sell when prices rise.

| | |
|---|---|
| Skills | Grain handling, moisture testing |
| Cost & equipment | Moisture meter, tarps or dryer, bag stock |
| Where to find work | Farmers, cereal traders, schools |
| Payment | Product sales and drying fees |
| Realistic earnings | Low to medium |
| Time to first income | Weeks |

**How to start:** Learn moisture testing; stock hermetic bags; train farmers.
**Pros:** Reduces post-harvest losses. **Cons & risks:** Seasonal demand.
**Scam warning:** Damp grain risks aflatoxin: test moisture properly.
**Kenya notes:** Aflatoxin contamination is a known problem in Kenyan maize; proper drying and storage prevent it.

## 831. Cassava flour processing

**What it is:** Turning cassava into flour, chips and other products.
**How it works:** Peel → chip → dry → mill → pack.

| | |
|---|---|
| Skills | Food processing, hygiene |
| Cost & equipment | Chipper, drying racks, milling access, packaging |
| Where to find work | Shops, schools, bakeries, households |
| Payment | Per kilo |
| Realistic earnings | Low to medium |
| Time to first income | Months |

**How to start:** Start small with local cassava; get KEBS and public health approvals for packed products.
**Pros:** Drought-tolerant crop; growing demand for flour blends. **Cons & risks:** Must process cassava properly to remove natural toxins.
**Scam warning:** Never sell unpacked flour as “certified” without approval.
**Kenya notes:** Cassava grows well in Coast, Western and Nyanza regions.

## 832. Solar fruit drying

**What it is:** Drying mangoes, pineapples, bananas and other fruit with solar dryers for snacks and export.
**How it works:** Buy fruit in glut seasons → slice → solar dry → pack.

| | |
|---|---|
| Skills | Food hygiene, packaging |
| Cost & equipment | Solar dryer, slicers, packaging |
| Where to find work | Supermarkets, schools, export buyers, online |
| Payment | Per pack or kilo |
| Realistic earnings | Low to medium |
| Time to first income | Months |

**How to start:** Build or buy a solar dryer; start with mangoes in glut season.
**Pros:** Reduces waste; long shelf life. **Cons & risks:** Quality control is essential.
**Scam warning:** Don't use sulphites or additives without understanding food rules.
**Kenya notes:** Mango gluts in Eastern and Coast regions waste tonnes of fruit every year.

## 833. Peanut butter production

**What it is:** Roasting and grinding groundnuts into peanut butter.
**How it works:** Source nuts → sort → roast → grind → jar and label.

| | |
|---|---|
| Skills | Food processing, hygiene |
| Cost & equipment | Roaster, grinder, jars |
| Where to find work | Shops, supermarkets, schools, online |
| Payment | Per jar |
| Realistic earnings | Low to medium |
| Time to first income | Weeks to months |

**How to start:** Start small, perfect your recipe, get KEBS certification before supermarket supply.
**Pros:** Popular product. **Cons & risks:** Aflatoxin risk in poor nuts.
**Scam warning:** Sort nuts carefully and test for aflatoxin.
**Kenya notes:** Groundnuts grow in Western, Nyanza and Eastern Kenya.

## 834. Fortified porridge flour blends

**What it is:** Mixing millet, sorghum, maize, soya and other grains into nutritious porridge flours.
**How it works:** Clean grains → roast → mill → blend → pack.

| | |
|---|---|
| Skills | Nutrition knowledge, hygiene |
| Cost & equipment | Milling access, packaging |
| Where to find work | Shops, schools, ECDE centres, hospitals |
| Payment | Per kilo |

| | |

**How it works:** Buy raw nuts → steam → shell → peel → roast → grade → pack.

| | |
|---|---|
| Skills | Processing, grading |

| Where to find work | Supermarkets, hotels, export |
| Payment | Per kilo |

| | |
|---|---|

## Summary

- Agro-processing includes shelling services, grain storage, cassava flour, dried fruit, peanut butter, porridge blends, coconut, cashew and macadamia processing, sisal, leather and bamboo products.
- KEBS standards and county public health approvals apply to food products.
- Control aflatoxin, hygiene and safety.

# More manufacturing and fabrication

Adding to manufacturing businesses (methods 616–632), these fabrication businesses serve farmers, builders and households.

## What these methods share

- **Quality:** strong, durable products win repeat orders.
- **Standards:** KEBS standards apply to many products.
- **Safety:** welding and machinery need protective gear.

## 972. Chain-link fencing production

**What it is:** Making chain-link fencing and barbed wire products.
**How it works:** Wire → weave on machine → roll and sell.

| | |
|---|---|
| Skills | Machine operation |
| Cost & equipment | Fencing machine, wire stock |
| Where to find work | Farmers, homeowners, schools, hardware shops |
| Payment | Per roll |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Start with one machine; sell to hardware shops and farmers.
**Pros:** Steady demand. **Cons & risks:** Wire price changes.
**Scam warning:** Use the wire gauge you advertise.
**Kenya notes:** Land fencing is common across Kenya.

## 973. Concrete posts and culverts

**What it is:** Casting fencing posts, culverts and ventilation blocks.
**How it works:** Moulds → mix and cast → cure → sell.

| | |
|---|---|
| Skills | Concrete work |
| Cost & equipment | Moulds, materials, curing space |
| Where to find work | Farmers, counties, contractors |
| Payment | Per piece |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Cure products properly for strength.
**Pros:** Constant demand. **Cons & risks:** Heavy transport.
**Scam warning:** Don't sell weak, uncured products.
**Kenya notes:** Counties and contractors buy culverts for roads.

## 974. Metal jiko (charcoal stove) fabrication

**What it is:** Making improved charcoal stoves (jikos) from metal and ceramic liners.
**How it works:** Cut metal → shape → fit liners → sell.

| | |
|---|---|
| Skills | Metalwork |
| Cost & equipment | Tools, metal sheets, liners |
| Where to find work | Households, markets, hardware shops |
| Payment | Per jiko |
| Realistic earnings | Low |
| Time to first income | Weeks |

**How to start:** Make efficient designs that save charcoal.
**Pros:** Daily household need. **Cons & risks:** Low prices.
**Scam warning:** Don't claim efficiency you can't show.
**Kenya notes:** Improved jikos cut charcoal use and smoke.

## 975. Ferro-cement water tanks

**What it is:** Building water tanks from cement and wire mesh on site.
**How it works:** Build mesh frame → plaster → cure → test.

| | |
|---|---|
| Skills | Masonry, ferro-cement technique |
| Cost & equipment | Materials, tools |
| Where to find work | Homes, schools, farms |
| Payment | Per tank |
| Realistic earnings | Medium |
| Time to first income | Weeks |

**How to start:** Train with a water NGO or experienced mason.
**Pros:** Cheaper than plastic for big tanks. **Cons & risks:** Skill needed to avoid cracks.
**Scam warning:** Cure properly and test for leaks.
**Kenya notes:** Rainwater harvesting programmes use ferro-cement tanks.

## 976. Poultry and livestock equipment fabrication

**What it is:** Making feeders, drinkers, cages, incubator frames and pig pens.
**How it works:** Design → fabricate → sell.

| | |
|---|---|
| Skills | Fabrication |
| Cost & equipment | Workshop tools |
| Where to find work | Poultry and livestock farmers, agrovets |
| Payment | Per item |
| Realistic earnings | Low to medium |
| Time to first income | Weeks |

**How to start:** Sell through agrovets and farmer groups.
**Pros:** Growing farming market. **Cons & risks:** Competition from imports.
**Scam warning:** Use safe, non-toxic materials.
**Kenya notes:** Poultry farming growth drives demand.

## 977. Tent and canvas making and repair

**What it is:** Making and repairing tents, tarpaulins, truck covers and awnings.
**How it works:** Measure → cut canvas → stitch → fit.

| | |
|---|---|
| Skills | Heavy-duty sewing |
| Cost & equipment | Industrial sewing machine, canvas |
| Where to find work | Event tent owners, truckers, shops, campsites |
| Payment | Per item or repair |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Start with repairs for tent hire businesses.
**Pros:** Repeat repair work. **Cons & risks:** Bulky materials.
**Scam warning:** Quote materials and labour clearly.
**Kenya notes:** Event tent hire (method 317) depends on repairs.

## Summary

- Fabrication businesses include fencing, concrete products, jikos, ferro-cement tanks, livestock equipment and tents.
- Quality, standards and safety matter.
- Honest specifications build trust.

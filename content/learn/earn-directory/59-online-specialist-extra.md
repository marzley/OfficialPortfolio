# More specialist online and technical niches

These are focused skills that companies hire for remotely or locally, adding to the specialist online work in methods 664–681.

## What these methods share

- **Portfolio:** show real examples of your work.
- **Tools:** learn the industry-standard tools for each niche.
- **Clients:** LinkedIn and freelance platforms reach them.

## 885. App store optimisation (ASO) specialist

**What it is:** Improving app listings (titles, keywords, screenshots, reviews) so more people find and install them.
**How it works:** Audit listing → keyword research → improve text and images → track installs.

| | |
|---|---|
| Skills | Marketing, keyword research, design sense |
| Cost & equipment | Low: laptop, ASO tools (free tiers) |
| Where to find work | App developers, startups, agencies |
| Payment | Per project or monthly |
| Realistic earnings | Low to medium |
| Time to first income | Weeks |

**How to start:** Practise on a friend's app; publish before-and-after results.
**Pros:** Niche with fewer competitors. **Cons & risks:** Results depend on the app's quality.
**Scam warning:** Never buy fake reviews or installs: stores ban apps for it.
**Kenya notes:** Kenyan fintech, agri and edtech apps need better store visibility.

## 886. Pinterest marketing manager

**What it is:** Running Pinterest accounts that drive traffic to blogs and online shops.
**How it works:** Create pins → schedule → optimise boards → track clicks.

| | |
|---|---|
| Skills | Design (Canva), keyword research |
| Cost & equipment | Low: laptop, scheduling tool |
| Where to find work | Bloggers, Etsy sellers, e-commerce brands abroad |
| Payment | Monthly retainer |
| Realistic earnings | Low to medium |
| Time to first income | Weeks |

**How to start:** Grow your own Pinterest account in one niche as proof.
**Pros:** Underserved skill. **Cons & risks:** Mostly overseas clients.
**Scam warning:** Avoid clients selling dubious products.
**Kenya notes:** Works fully remotely from Kenya.

## 887. UX writer

**What it is:** Writing the words inside apps and websites: buttons, messages, onboarding and errors.
**How it works:** Understand users → write clear microcopy → test and improve.

| | |
|---|---|
| Skills | Clear writing, user empathy |
| Cost & equipment | Low: laptop, design tools (Figma basics) |
| Where to find work | Tech companies, startups, design agencies |
| Payment | Per project or salary |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Rewrite confusing screens from real apps as portfolio pieces.
**Pros:** Growing tech role. **Cons & risks:** Needs a portfolio to break in.
**Scam warning:** Ignore “pay to join” UX bootcamps that promise jobs.
**Kenya notes:** Kiswahili UX writing is valuable for apps serving East Africa.

## 888. GIS mapping and analysis

**What it is:** Creating maps and analysing location data for planning, farming, health and conservation.
**How it works:** Collect data → analyse in GIS software (e.g. QGIS) → produce maps and reports.

| | |
|---|---|
| Skills | GIS software, data analysis |
| Cost & equipment | Laptop; QGIS is free |
| Where to find work | NGOs, counties, researchers, surveyors, utilities |
| Payment | Per project or contract |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Learn QGIS with free courses; build sample maps of your county.
**Pros:** Valuable, technical skill. **Cons & risks:** Data access can be hard.
**Scam warning:** Respect data licences and privacy.
**Kenya notes:** Counties, NGOs and conservation groups use GIS heavily.

## 889. CAD drafting for manufacturing and engineering

**What it is:** Drawing parts, machines and fabrication plans in CAD software.
**How it works:** Brief → 2D/3D drawings → revisions → final files.

| | |
|---|---|
| Skills | CAD software (AutoCAD, FreeCAD, Fusion) |
| Cost & equipment | Laptop, software |
| Where to find work | Fabricators, engineers, manufacturers, 3D printing businesses |
| Payment | Per drawing or project |
| Realistic earnings | Medium |
| Time to first income | Months |

**How to start:** Learn a CAD tool; draw real parts from local workshops.
**Pros:** Works locally and remotely. **Cons & risks:** Needs technical accuracy.
**Scam warning:** Use licensed software for commercial work.
**Kenya notes:** Different from architectural drafting (method 354).

## 890. Online exam proctor

**What it is:** Supervising online exams through video to make sure candidates follow the rules.
**How it works:** Join a proctoring company → monitor sessions → report incidents.

| | |
|---|---|
| Skills | Attention, reliability, good internet |
| Cost & equipment | Laptop, stable internet, quiet space |
| Where to find work | Proctoring companies, universities, certification bodies |
| Payment | Per hour or session |
| Realistic earnings | Low |
| Time to first income | Weeks |

**How to start:** Apply to proctoring companies and training institutions.
**Pros:** Remote work. **Cons & risks:** Shift hours across time zones.
**Scam warning:** Real employers don't charge for “proctor training kits”.
**Kenya notes:** Online exams for certifications and universities need proctors.

## Summary

- Specialist niches include ASO, Pinterest marketing, UX writing, GIS mapping, CAD drafting and online exam proctoring.
- Build a portfolio with real or practice examples.
- Never buy fake reviews or pay for job promises.

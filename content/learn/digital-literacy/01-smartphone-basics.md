# Getting the most from your smartphone

For most Kenyans the phone **is** the computer: M-Pesa, WhatsApp, school portals, eCitizen, job applications and online classes all happen on it. A few skills make it faster, safer and cheaper to use.

## Set it up properly

1. **Screen lock**: a PIN (6 digits or more), pattern or fingerprint. Never "None".
2. **Google account** (Android) or Apple ID: needed for the Play Store, backups and finding a lost phone. Use a strong password and turn on 2-step verification.
3. **Find My Device** (Android: Settings → Security → Find My Device; iPhone: Find My): locate, lock or erase a lost phone.
4. **Automatic updates**: Settings → System → Software update, and Play Store → Settings → Auto-update apps.
5. **Backups**: Google One / iCloud for contacts and photos; WhatsApp's own chat backup (Settings → Chats → Chat backup).

## Save data and money

| Tip | Where |
|---|---|
| Turn on **Data Saver** | Settings → Network & internet → Data Saver |
| See which apps use the most data | Settings → Network → Data usage |
| Stop apps using data in the background | App info → Mobile data → Background data off |
| WhatsApp: don't auto-download media | WhatsApp → Settings → Storage and data |
| YouTube: lower quality or download on Wi-Fi | ⚙ → Quality |
| Update apps on Wi-Fi only | Play Store settings |
| Use "Lite" versions | Facebook Lite, Messenger Lite, Google Go |

## Free up storage

- WhatsApp → Settings → Storage and data → **Manage storage**: delete big videos and forwarded files.
- Google Photos → **Free up space** (after backing up).
- Clear the cache of heavy apps: Settings → Apps → App → Storage → Clear cache.
- Uninstall apps you haven't opened in months.

## Useful skills

| Skill | How (Android, similar on iPhone) |
|---|---|
| **Screenshot** | Power + Volume down |
| **Share your internet (hotspot)** | Settings → Network → Hotspot & tethering |
| **Scan a QR code** | Open the camera and point it at the code |
| **Scan documents to PDF** | Google Drive → + → Scan (great for applications) |
| **Copy text from a photo** | Google Lens (in the camera or Photos) |
| **Voice typing** | Tap the microphone on the keyboard |
| **Translate** | Google Translate app, including the camera mode |
| **Split screen** | Recent apps → app icon → Split screen |

## App permissions: who can see what

Settings → Privacy → **Permission manager** shows which apps can use your camera, microphone, location, contacts and SMS. Remove permissions that don't make sense (why does a torch app need your contacts?). Be very careful with apps that request **SMS** or **accessibility** access: fraud apps use them to read M-Pesa messages and one-time codes.

## Battery care

- Lower screen brightness or use auto-brightness and **dark mode**.
- Turn off Wi-Fi, Bluetooth and location when not needed.
- Use the original or a good-quality charger. Cheap chargers can damage batteries.
- Avoid leaving the phone in hot places (a car dashboard).

## Accessibility features

Bigger text (Settings → Display → Font size), **TalkBack** (a screen reader for blind users), magnification, and captions for videos help family members with poor eyesight or hearing.

# Canva essentials: interface, templates, text, photos, elements, brand kit, magic tools, teamwork and exporting

**Canva** is a free online design tool that runs in the browser and as a phone app. With it you can design social media posts, posters, flyers, business cards, presentations, CVs, invitations, logos, videos and simple websites, using thousands of templates. Many Kenyan freelancers, small business owners, church and school media teams, and social media managers use Canva daily. This unit is a full practical tour: from creating your first design to exporting print-ready files and working with clients and teams.

## Getting started

1. Sign up at canva.com (or install the app) with email or Google.
2. **Free plan**: many templates, photos and elements; enough to start earning.
3. **Canva Pro**: premium templates and images, Brand Kits, background remover, Magic Resize, more storage, scheduling. Teams plans share it.
4. **Canva for Education** (eligible teachers/students) and **Canva for Nonprofits** (eligible NGOs) offer premium features free; check eligibility on Canva's site.

## The interface

| Area | Purpose |
|---|---|
| **Home** | Search templates, recent designs, create new designs |
| **Editor canvas** | Your design |
| **Side panel** | Design (templates), Elements, Text, Brand, Uploads, Draw, Projects, Apps |
| **Top toolbar** | Options for the selected item (font, colour, effects, position, transparency) |
| **Bottom bar** | Pages, zoom, notes, grid view |
| **Share/Download** | Export, share links, present, publish |

## Start a design

- **From a template**: search "church fundraiser poster", "salon Instagram post", "business card". Customise colours, text and images so it doesn't look like everyone else's.
- **Custom size**: "Create a design" → "Custom size", e.g. 1080×1350 px (Instagram portrait), 1280×720 px (YouTube thumbnail), A4 for print.

Common sizes:

| Design | Size |
|---|---|
| Instagram post (portrait) | 1080×1350 px |
| Instagram/Facebook square | 1080×1080 px |
| Story/Status/TikTok/Reels | 1080×1920 px |
| Facebook cover | 1640×624 px (check current specs) |
| YouTube thumbnail | 1280×720 px |
| LinkedIn post | 1200×1200 or 1200×627 px |
| A4 poster/flyer | 210×297 mm |
| A5 flyer | 148×210 mm |
| Business card | 85×55 mm (Kenya/Europe common) or 3.5×2 in |

## Text

- Add headings, subheadings and body text from the **Text** panel.
- Choose 1–2 fonts; keep sizes in a clear hierarchy (e.g. 80 / 40 / 24 px on a social post).
- Adjust **letter spacing** and **line spacing** (toolbar → spacing).
- **Effects**: shadow, outline, background behind text ("splice", "hollow"), curve. Use sparingly; readability first.
- Use **text boxes on shapes** to keep text readable over busy photos, or add a dark transparent overlay to the photo.

## Photos

- **Uploads**: add client photos/logos (ask for high resolution).
- **Crop** (double-click), **flip**, **filters**, **adjust** (brightness, contrast, warmth, saturation).
- **Background remover** (Pro): cut out products or people; then place on brand-coloured backgrounds.
- **Frames**: drag photos into shapes (circles, phone mock-ups, letters).
- **Transparency**: fade images for backgrounds.

## Elements

Search the Elements panel for shapes, lines, icons, illustrations, stickers, **frames**, **grids** (photo collages), charts, tables and QR codes (handy for posters linking to WhatsApp or websites). Combine simple shapes and icons for clean professional looks.

## Layers, alignment and organisation

| Tool | How |
|---|---|
| **Position** | Toolbar → Position: bring forward/back, align left/centre/right, tidy up spacing |
| **Layers** | Position → Layers tab: reorder, select hidden items |
| **Group** | Select several items → Group (Ctrl/Cmd+G) to move them together |
| **Lock** | Lock backgrounds or approved parts to avoid moving them accidentally |
| **Rulers and guides** | File → Settings → Show rulers and guides; show margins; show print bleed |
| **Smart guides** | Pink lines appear when items align or are evenly spaced |

## Brand Kit

Store a client's **logos, colours and fonts** (Brand panel). Every design then uses the same brand assets, which is key for social media managers handling several clients. On the free plan, save brand colours in a design as a reference and duplicate a "master template" for each client.

## Magic and AI tools

Canva includes AI features (some Pro-only, names change over time): text-to-image generation, **Magic Write** (text suggestions), **Magic Edit/Grab/Expand** (edit parts of photos), **Magic Resize** (resize a design to other formats in one click), background removal, translation, and animations. Use AI as a helper, check outputs carefully (spelling, hands and faces in generated images, accuracy), and respect client brand rules and Canva's licence terms.

## Collaboration

- **Share** a link with view, comment or edit access. Clients can comment directly on the design.
- **Teams**: share folders and brand kits with colleagues.
- **Templates for clients**: share a "use as template" link so clients make simple edits themselves (a service you can sell).
- **Version history** (Pro): restore earlier versions.

## Exporting

| Purpose | Download as |
|---|---|
| Social media posts | PNG (sharp text) or JPG (photos, smaller) |
| Website images | PNG/JPG, compress afterwards; SVG for simple graphics (Pro) |
| Print | **PDF Print**, tick **crop marks and bleed**, flatten PDF if the printer asks |
| Video/animated posts | MP4 (or GIF for short loops) |
| Presentations | PDF or PowerPoint, or present directly |

Before printing: turn on **Show print bleed**, keep text inside the margins, use high-resolution images, and send a PDF proof to the client.

## Time-saving habits

- Shortcuts: `T` text, `R` rectangle, `L` line, `C` circle, `Ctrl/Cmd+D` duplicate, `Ctrl/Cmd+Shift+L` lock, `Alt+Shift+T/C/B` align (shortcuts vary; see Canva's help).
- Duplicate pages to create a series of consistent posts.
- Build reusable templates for each client.
- Keep folders: Client → Project → Final files.
- Check spelling of names, dates, prices and phone numbers before exporting.

:::think A client wants the same Christmas promotion as an Instagram post, a WhatsApp Status, a Facebook cover and an A4 printed poster. How would you work efficiently in Canva?
Design the master (e.g. the Instagram post) with the brand kit, then use Magic Resize (Pro) or duplicate into each custom size, and adjust layouts for each format (text larger on Status, safe zones on covers). For the A4 poster, use high-resolution photos, show print bleed, keep text in margins, and export a PDF Print with crop marks and bleed. Share a comment link for approval before final export.
:::

## Summary

- Canva is a free browser/phone design tool; Pro adds brand kits, premium assets, background remover and resizing; Education/Nonprofit plans exist.
- Start from templates (customised) or custom sizes; know common social and print sizes.
- Work with text hierarchy, photo editing, elements, frames, grids and QR codes; organise with layers, alignment, grouping and locking.
- Use brand kits for consistency, AI tools carefully, and comment/share links for collaboration.
- Export PNG/JPG for social, MP4 for video, and PDF Print with bleed and crop marks for printing.

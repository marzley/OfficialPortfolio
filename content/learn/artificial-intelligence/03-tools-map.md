# Level 1: The map of AI tools (what to use for what)

There are thousands of AI tools, and new ones appear every week. You don't need to know them all. You need to know the **categories** and one or two good tools in each. Many have free plans; prices and features change often.

## Chat assistants (the all-rounders)

| Tool | Best for |
|---|---|
| [ChatGPT](https://chatgpt.com) | General questions, writing, images, voice |
| [Claude](https://claude.ai) | Long documents, careful writing, analysis, coding |
| [Gemini](https://gemini.google.com) | Google Workspace (Gmail, Docs, Sheets), Android |
| [Microsoft Copilot](https://copilot.microsoft.com) | Windows and Microsoft 365 (Word, Excel, PowerPoint) |
| Meta AI | Quick help inside WhatsApp and Instagram |

## Research and studying

| Tool | Best for |
|---|---|
| [Perplexity](https://www.perplexity.ai) | Answers with sources and links |
| [NotebookLM](https://notebooklm.google.com) | Upload your notes/PDFs and ask questions only about them; makes study guides and audio summaries |
| [Google Scholar](https://scholar.google.com) (not AI, but essential) | Finding real academic papers to cite |

## Images and design

| Tool | Best for |
|---|---|
| [Canva](https://www.canva.com) (Magic Studio) | Posters, social posts, removing backgrounds, AI images inside designs |
| ChatGPT / Gemini image generation | Quick illustrations and concept images from a description |
| [Adobe Firefly](https://firefly.adobe.com) | Images built for commercial use, inside Adobe apps |
| [Ideogram](https://ideogram.ai) | Images with readable text (posters, logos ideas) |
| [Microsoft Designer](https://designer.microsoft.com) | Free social graphics and invitations |

## Video and audio

| Tool | Best for |
|---|---|
| [CapCut](https://www.capcut.com) | Auto-captions, templates, AI effects for TikTok/Reels |
| [Runway](https://runwayml.com) | AI video generation and editing |
| [ElevenLabs](https://elevenlabs.io) | Realistic voice-overs (use only voices you have the right to use) |
| [Descript](https://www.descript.com) | Edit podcasts and videos by editing the transcript |

## Writing and office work

| Tool | Best for |
|---|---|
| [Grammarly](https://www.grammarly.com) | Grammar, tone and clarity |
| Copilot in Microsoft 365 / Gemini in Google Workspace | Drafting documents, Excel formulas, slide decks, email summaries |
| [Otter.ai](https://otter.ai) / Google Meet notes | Meeting transcripts and summaries |

## Coding

| Tool | Best for |
|---|---|
| [GitHub Copilot](https://github.com/features/copilot) | Code suggestions inside VS Code |
| [Claude Code](https://www.anthropic.com/claude-code) | An AI coding agent in your terminal and editor |
| [Cursor](https://cursor.com) | An AI-first code editor |
| Chat assistants | Explaining errors, writing small scripts, learning to code |

## Automation (connecting apps)

| Tool | Best for |
|---|---|
| [Zapier](https://zapier.com) | "When X happens, do Y" between thousands of apps, with AI steps |
| [Make](https://www.make.com) | Visual automations, cheaper for many steps |
| [n8n](https://n8n.io) | Open-source automation you can host yourself |

## How to choose a tool

1. **Start with a chat assistant**: it can do 80% of what most people need.
2. **Add a specialist tool** only when you hit a limit (better images, video, meeting notes).
3. **Check the free plan, privacy policy and commercial-use terms** before using it for clients.
4. **Don't chase every new app**: depth with a few tools beats shallow use of many.

## A starter kit by goal

| Goal | Starter kit |
|---|---|
| Student | Chat assistant + NotebookLM + Google Scholar |
| Small business owner | Chat assistant + Canva + WhatsApp Business |
| Content creator | Chat assistant + CapCut + Canva |
| Office worker | Copilot or Gemini in your office suite + a chat assistant |
| Aspiring developer | Chat assistant + GitHub Copilot or Claude Code + this hub's coding lessons |

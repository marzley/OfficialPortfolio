# Level 1: The map of AI tools (what to use for what)

There are thousands of AI tools, and new ones appear every week. You don't need to know them all. You need to know the **categories** and one or two good tools in each. Many have free plans; prices and features change often.

## Chat assistants (the all-rounders)

| Tool | Best for |
|---|---|
| [ChatGPT](https://chatgpt.com) | General questions, writing, images, voice |
| [Claude](https://claude.ai) | Long documents, careful writing, analysis, coding |
| [Gemini](https://gemini.google.com) | Google Workspace (Gmail, Docs, Sheets), Android |
| [Microsoft Copilot](https://copilot.microsoft.com) | Windows and Microsoft 365 (Word, Excel, PowerPoint) |
| Meta AI | Quick help inside WhatsApp and Instagram |

## Research and studying

| Tool | Best for |
|---|---|
| [Perplexity](https://www.perplexity.ai) | Answers with sources and links |
| [NotebookLM](https://notebooklm.google.com) | Upload your notes/PDFs and ask questions only about them; makes study guides and audio summaries |
| [Google Scholar](https://scholar.google.com) (not AI, but essential) | Finding real academic papers to cite |

## Images and design

| Tool | Best for |
|---|---|
| [Canva](https://www.canva.com) (Magic Studio) | Posters, social posts, removing backgrounds, AI images inside designs |
| ChatGPT / Gemini image generation | Quick illustrations and concept images from a description |
| [Adobe Firefly](https://firefly.adobe.com) | Images built for commercial use, inside Adobe apps |
| [Ideogram](https://ideogram.ai) | Images with readable text (posters, logos ideas) |
| [Microsoft Designer](https://designer.microsoft.com) | Free social graphics and invitations |

## Video and audio

| Tool | Best for |
|---|---|
| [CapCut](https://www.capcut.com) | Auto-captions, templates, AI effects for TikTok/Reels |
| [Runway](https://runwayml.com) | AI video generation and editing |
| [ElevenLabs](https://elevenlabs.io) | Realistic voice-overs (use only voices you have the right to use) |
| [Descript](https://www.descript.com) | Edit podcasts and videos by editing the transcript |

## Writing and office work

| Tool | Best for |
|---|---|
| [Grammarly](https://www.grammarly.com) | Grammar, tone and clarity |
| Copilot in Microsoft 365 / Gemini in Google Workspace | Drafting documents, Excel formulas, slide decks, email summaries |
| [Otter.ai](https://otter.ai) / Google Meet notes | Meeting transcripts and summaries |

## Coding

| Tool | Best for |
|---|---|
| [GitHub Copilot](https://github.com/features/copilot) | Code suggestions inside VS Code |
| [Claude Code](https://www.anthropic.com/claude-code) | An AI coding agent in your terminal and editor |
| [Cursor](https://cursor.com) | An AI-first code editor |
| Chat assistants | Explaining errors, writing small scripts, learning to code |

## Automation (connecting apps)

| Tool | Best for |
|---|---|
| [Zapier](https://zapier.com) | "When X happens, do Y" between thousands of apps, with AI steps |
| [Make](https://www.make.com) | Visual automations, cheaper for many steps |
| [n8n](https://n8n.io) | Open-source automation you can host yourself |

## How to choose a tool

1. **Start with a chat assistant**: it can do 80% of what most people need.
2. **Add a specialist tool** only when you hit a limit (better images, video, meeting notes).
3. **Check the free plan, privacy policy and commercial-use terms** before using it for clients.
4. **Don't chase every new app**: depth with a few tools beats shallow use of many.

## Choosing tools wisely

New AI tools appear every week, and many promise the same thing. Instead of chasing every new name, learn **categories** and a few reliable tools in each. Most people need one good general assistant, one research tool that shows sources, and maybe one specialist tool for their work (design, coding, transcription).

## Questions to ask before using any AI tool

| Question | Why it matters |
|---|---|
| What does it cost, and what's in the free plan? | Free tiers often limit usage, quality or features |
| Where does my data go? Is it used for training? | Important for work documents and personal information |
| Does it show sources? | Needed for research, school work and facts |
| Does it work well on my phone and internet connection? | Many users rely on mobile data |
| Can I export my work? | Avoid being locked in |
| Is it from a reputable company? | Fake "AI" apps can be scams or malware |
| Does my school or employer allow it? | Policies differ |

## Matching tools to tasks

| Task | Tool category | Tip |
|---|---|---|
| Explain, draft, brainstorm | General chat assistant | Give context and ask for a specific format |
| Research with references | Search-based AI / research assistants | Open and read the sources it links |
| Study from your own notes | Notebook-style tools where you upload documents | Answers stay grounded in your material |
| Transcribe meetings or interviews | Speech-to-text / transcription tools | Check names, numbers and technical terms |
| Translate | Translation tools and assistants | Have a fluent speaker check important texts |
| Design posters and social posts | Design tools with AI features | Keep brand colours and fonts consistent |
| Generate images | Image generators | Check hands, text and details; respect copyright and likeness |
| Write and debug code | Coding assistants | Read and test all code before using it |
| Automate repetitive work | Automation platforms with AI steps | Start with simple, low-risk workflows |

## Spotting fake or risky AI apps

- Download only from official app stores and check the developer name, reviews and download counts.
- Be suspicious of apps asking for unnecessary permissions (SMS, contacts, accessibility services).
- Avoid "AI investment bots" promising guaranteed profits; these are common scams.
- Don't install modified ("premium unlocked") versions of AI apps.
- If an "AI assistant" asks for your M-Pesa PIN, bank login or OTP, it's a scam.

## Building your personal toolkit

| Goal | Starter kit |
|---|---|
| Student | General assistant (explanations, quizzes) + notebook tool for your notes + a reference manager |
| Office worker | Assistant inside your office suite or a general assistant + transcription for meetings |
| Small business owner | General assistant for posts and replies + design tool + WhatsApp Business quick replies |
| Developer | Coding assistant in your editor + documentation search + a general assistant for explanations |
| Content creator | Scriptwriting help + video editing with auto-captions + thumbnail design tool |

Learn one tool well before adding another. Deep skill with a few tools beats shallow use of many.

## Keeping up without getting overwhelmed

- Follow a few trustworthy sources (official product blogs, reputable tech news, local tech communities).
- Test new tools with a real task from your work; keep them only if they save time or improve quality.
- Review your subscriptions every few months and cancel unused ones.

## Practice

1. List your top three tasks that AI could help with and choose a tool category for each.
2. Check the privacy settings and data policy of one AI tool you use.
3. Try a research tool that shows sources and verify two of its links.
4. Compare the free plans of two similar tools and decide which suits you.
5. Write a short "AI toolkit" for your job or studies with one tool per task.

:::think A colleague wants to upload the company's customer list to a free AI tool to "find patterns". What should be checked first?
Whether company policy allows it, what the tool does with uploaded data (storage, training, sharing), and whether the data contains personal information covered by the Data Protection Act. Safer options: remove or anonymise personal details, use an approved business tool with proper data agreements, or analyse the data with internal tools.
:::

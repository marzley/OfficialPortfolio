# Level 5: Your AI career roadmap: from user to AI pro

You've gone from "what is AI?" to building classifiers, neural networks and AI-powered apps. This final lesson maps the careers AI opens up and exactly what to learn next for each.

## The AI skills ladder

| Level | You can | Typical roles and income paths |
|---|---|---|
| 1. **AI user** | Use chat assistants safely and effectively | Every job: more productive office work, study, small business |
| 2. **Power user** | Prompting, fact-checking, AI in Office/Workspace, content creation | Virtual assistant, social media manager, content creator, AI trainer for teams |
| 3. **Automation builder** | Custom assistants, no-code workflows (Zapier/Make/n8n) | AI automation freelancer, operations specialist |
| 4. **Technical AI practitioner** | Python, data analysis, machine learning basics | Data analyst, junior data scientist, AI data specialist |
| 5. **AI engineer** | Build AI apps: APIs, RAG, tools, agents, evaluation | AI engineer, full-stack developer with AI, ML engineer |
| 6. **Researcher / specialist** | Deep learning, training and fine-tuning models, maths | ML researcher, NLP specialist (for example African languages) |

You don't need to reach level 6. Levels 2 to 5 already open many well-paid paths.

## Path A: AI for your current job (Levels 1 to 3)

1. Complete Levels 1 to 3 of this course.
2. Use AI daily in your work for a month; keep a log of time saved.
3. Learn your office suite deeply: **Excel/Sheets**, **Word/Docs**, **PowerPoint** (all in this hub).
4. Build 2 automations that save your team real time.
5. Offer to train colleagues. People who make teams more productive get promoted.

## Path B: Data analyst (Levels 4 and beyond)

| Learn | Where |
|---|---|
| Excel / Google Sheets (pivot tables, charts) | This hub |
| **SQL** | This hub: the SQL subject with a live database |
| **Python** (pandas for data, matplotlib for charts) | This hub's Python subject, then pandas tutorials |
| Statistics basics (averages, spread, correlation, sampling) | Free online courses, Khan Academy |
| Dashboards (Power BI, Looker Studio) | Free Microsoft and Google learning paths |

Portfolio: 3 projects analysing real Kenyan data (for example open data from the Kenya National Bureau of Statistics), each with a clear question, charts and conclusions.

## Path C: AI / ML engineer (Levels 4 to 5)

1. **Programming**: Python solidly (functions, classes, files, APIs), plus Git and GitHub.
2. **Maths, step by step**: linear algebra (vectors, matrices), probability and statistics, and calculus ideas (gradients). Learn them alongside code, not before everything.
3. **Classic machine learning**: scikit-learn (regression, classification, trees, evaluation).
4. **Deep learning**: PyTorch; neural networks for images and text.
5. **LLM applications**: AI APIs, prompt design, RAG, tool use, agents, evaluation, cost and safety.
6. **Deploying**: web backends (Python/FastAPI, PHP, Node), databases, cloud basics.

## Projects that get you hired

Build things that solve Kenyan problems and show them on GitHub and LinkedIn:

- A **Kiswahili/English FAQ assistant** for a school, clinic or county service, using RAG.
- A **crop disease classifier** from leaf photos (public datasets exist).
- A **sales forecasting** dashboard for a small business.
- An **M-Pesa statement analyser** that categorises spending (with privacy built in).
- A **WhatsApp-style customer service bot** with tool use for order status.
- A **study helper** that generates quizzes from notes, with answers checked against the source.

For each: a README (problem, approach, results, limitations), a demo video and honest evaluation numbers.

## AI in Kenya

- Kenya's government has published a **national AI strategy** and the **Data Protection Act** governs how personal data is used: learn both if you build AI for organisations here.
- Nairobi has a large AI data workforce (annotation and data operations), plus startups using AI in fintech, agriculture, health and education.
- Local language AI (Kiswahili and other Kenyan languages) is an area where African developers have a real advantage.
- Communities: university AI clubs, Google Developer Groups, data science meetups, and Kaggle competitions are great places to learn and get noticed.

## Staying current without burning out

AI changes fast, but fundamentals (programming, data, statistics, clear thinking, communication) last. Spend most of your time on fundamentals and building projects, and a little time each week following trusted updates. Ignore hype that promises overnight riches.

# Keyboard, mouse, touch typing and shortcuts

Fast, accurate typing and a handful of shortcuts will save you hours every week, whether you're writing reports, coding, or doing data entry jobs.

## Parts of the keyboard

| Area | Keys | Use |
|---|---|---|
| Alphanumeric | Letters, numbers, symbols | Typing text |
| Modifier keys | **Shift**, **Ctrl**, **Alt**, **Windows**/**Cmd** | Held with other keys for shortcuts |
| Function keys | F1–F12 | F1 help, F2 rename, F5 refresh, F11 full screen |
| Navigation | Arrows, Home, End, Page Up/Down | Moving around text |
| Editing | Backspace (deletes left), Delete (deletes right), Insert | |
| Numeric keypad | 0–9, + − * / | Fast number entry (turn on with Num Lock) |
| Others | Esc, Tab, Caps Lock, Enter, Print Screen | |

## Mouse and touchpad

| Action | Does |
|---|---|
| Left click | Select |
| Double click | Open |
| Right click | Context menu (options for that item) |
| Click and drag | Move or select several items |
| Scroll wheel / two-finger swipe | Scroll |
| Ctrl + scroll | Zoom in/out |

## Touch typing: type without looking

1. **Home row**: left fingers on `A S D F`, right on `J K L ;`. Feel the small bumps on **F** and **J**.
2. Each finger covers the keys above and below its home key.
3. Thumbs press the **space bar**.
4. Look at the screen, not the keyboard. It feels slow at first, then becomes much faster than two-finger typing.

Practise **15 minutes a day** on free sites like typing.com, keybr.com or monkeytype.com. A good target is **40+ words per minute** at 95% accuracy; data entry and transcription jobs often ask for 50–60 wpm.

## Typing symbols

- `@` is **Shift + 2** on most keyboards.
- Capital letters: hold **Shift** (Caps Lock for long capital text).
- Accents and special characters: Win + . (full stop) opens the emoji and symbol panel.

## Good posture

Sit straight, screen at eye level about an arm's length away, wrists straight, feet flat. Take a short break every 30–60 minutes, and look at something far away to rest your eyes.

## Why typing and shortcuts matter

Typing speed and shortcut skills save hours every week. Data entry clerks, secretaries, transcribers, writers, programmers, students writing assignments and anyone who works online type all day. Many job tests and freelancing tasks (transcription, data entry, virtual assistance) measure typing speed and accuracy directly. A person who types 50 words per minute accurately and uses shortcuts can finish in half a day what takes others a whole day.

## Typing speed benchmarks

| Level | Words per minute (WPM) | Typical for |
|---|---|---|
| Beginner | Under 25 | Hunt-and-peck typing, looking at keys |
| Average | 35 to 40 | Many office workers |
| Good | 50 to 70 | Secretaries, writers, programmers |
| Professional | 70+ | Transcriptionists, court reporters |

Accuracy matters more than speed: aim for 95% or better before pushing speed. Fixing errors costs more time than typing slowly.

## A 4-week touch typing plan

| Week | Focus | Daily practice (15 to 20 minutes) |
|---|---|---|
| 1 | Home row (ASDF JKL;) and posture | Lessons for home row only, eyes on screen |
| 2 | Top row and bottom row | Add one row at a time; slow and accurate |
| 3 | Numbers, capitals with Shift, punctuation | Type short paragraphs |
| 4 | Real text | Type articles, emails, your notes; take a 1-minute speed test daily |

Free practice sites include typing.com, keybr.com and monkeytype.com. Practise a little **every day**; short daily sessions beat one long session a week.

## Finger positions

```
Left hand:  pinky A   ring S   middle D   index F (and G)
Right hand: index J (and H)   middle K   ring L   pinky ;
Thumbs:     space bar
```

Each finger is responsible for the keys above and below its home key. The bumps on F and J let you find the home row without looking.

## Text editing shortcuts that save the most time

| Shortcut | Action |
|---|---|
| Ctrl + ← / → | Jump one word left/right |
| Ctrl + Shift + ← / → | Select one word at a time |
| Home / End | Start / end of the line |
| Ctrl + Home / Ctrl + End | Start / end of the document |
| Shift + Home / End | Select to the start / end of the line |
| Ctrl + Backspace | Delete the whole previous word |
| Ctrl + Delete | Delete the next word |
| Double-click | Select a word; triple-click selects a paragraph |
| Ctrl + F / Ctrl + H | Find / Find and replace |
| Ctrl + Shift + V (many apps) | Paste as plain text (no formatting) |

Ctrl + Backspace alone can save many key presses compared with holding Backspace.

## Phone typing tips

- Turn on **glide/swipe typing** in Gboard or SwiftKey settings to type by sliding your finger.
- Use **voice typing** (the microphone on the keyboard) for long messages; it understands English and Kiswahili.
- Create **text shortcuts** (Gboard: Settings → Dictionary → Personal dictionary): type "@@" to insert your email, or "addr" for your address.
- Long-press letters for accented characters, and the full stop key for punctuation.
- Use clipboard history in Gboard to paste recent items.

## Accessibility helpers

- **Sticky Keys** (press Shift five times on Windows): press shortcut keys one at a time instead of together.
- **On-screen keyboard** (Windows + Ctrl + O): useful if a key is broken.
- **Magnifier** (Windows + Plus): zoom part of the screen.
- **Dictation**: type with your voice if typing is difficult.

## Healthy computer habits

- **20-20-20 rule**: every 20 minutes, look at something 20 feet (6 metres) away for 20 seconds to rest your eyes.
- Keep wrists straight, not bent upward; elbows at about 90 degrees.
- Top of the screen at or slightly below eye level; laptop users can raise the laptop and use an external keyboard.
- Stand and stretch every hour.
- Good lighting without glare on the screen.

## Practice

1. Take a 1-minute typing test today and record your WPM and accuracy. Repeat weekly for a month.
2. Write a 100-word paragraph using only the keyboard: no mouse for selecting, moving or deleting.
3. Turn on Clipboard history and copy three items, then paste the oldest.
4. Rename five files with F2 and create a folder with Ctrl + Shift + N.
5. Set up a text shortcut on your phone for your email address.

:::think Two clerks type 40 WPM, but one finishes data entry much faster. What skills might the faster one be using?
Touch typing with eyes on the source document instead of the keys, keyboard navigation (Tab between fields, Ctrl + arrows, Home/End), copy-paste and clipboard history, Find and replace for repeated corrections, and few errors so less time is spent fixing them. Accuracy and shortcuts often matter more than raw speed.
:::
